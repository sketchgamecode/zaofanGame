## 1. 界面总体布局 (Overall Layout)

黑市与奇珍阁共享同一套底层 UI 结构，采用经典的“左人右店”分屏布局。

### 1.1 左侧区域：角色与装备面板 (Player Panel)
*   此区域属于全局中枢组件，**必须严格遵守** `Character_Panel_UI_Spec_V1.md` 中的所有视觉布局（Avatar、经验条、5 个背包槽）与交互规范（加点、衍生属性显示）。
*   在黑市场景下，左侧的装备槽与背包槽需无缝衔接右侧商店物品的全局 DND 拖拽交互。

### 1.2 右侧区域：商店面板 (Shop Panel)
*   **NPC 立绘区域 (NPC Figure)**：位于右侧面板顶部，占据约 1/3 高度。
*   **NPC 对话气泡 (Chat Bubble)**：悬浮在 NPC 头部，用于显示随机或交互式的风味台词。
*   **商品货架 (Item Grid)**：2 行 x 3 列的网格布局，展示 6 件待售物品。
*   **底部操作栏 (Action Bar)**：
    *   **当前持有资源**：显示玩家当前的铜钱 (Copper) 和令牌 (Tokens)。
    *   **刷新按钮 (Refresh Button)**：醒目的按钮，标明消耗“1 令牌”。

## 2. 视觉资产与沉浸感设计 (Visual Assets & Theme)

### 2.1 背景设计 (Backgrounds)
*   **兵器铺 (Weapon Shop)**：
    *   *氛围*：昏暗、炽热、充满铁锈味。
    *   *元素*：燃烧的锻造炉，火星飘动，背景墙上挂着各种有大宋特色（但造型夸张）的冷兵器，如血滴子、狼牙棒、破损的步人甲。
*   **奇珍阁/鬼市 (Magic Shop)**：
    *   *氛围*：阴森、神秘、幽绿或幽紫色调。
    *   *元素*：漂浮的符文，冒着绿光的香炉，背景架子上摆放着泡在福尔马林（或古代防腐液）里的不明生物标本、发光的珠子和泛黄的古籍。

### 2.2 NPC 设定与表现 (NPC Figures)
*   **兵器铺老板【铁瞎子】**：
    *   *形象*：肌肉虬结但瞎了一只眼的独眼龙，满身汗水和碳灰，脖子上搭着一条脏毛巾。
    *   *待机动画*：拿着铁锤在砧板上敲打，偶尔用毛巾擦汗。
    *   *交互台词*：“摸坏了要赔的，你赔得起吗？”、“这刀杀过人，你要是怕鬼就别买。”
*   **奇珍阁老板【半仙/阴阳人】**：
    *   *形象*：穿着宽大道袍，面容惨白，雌雄难辨，手指干枯细长。
    *   *待机动画*：手里盘着两个发光的骷髅核桃，眼睛不时闪烁异光。
    *   *交互台词*：“活人用的东西我这儿没有。”、“你印堂发黑，买这个能让你晚死两天。”

## 3. 核心交互与微反馈 (Core Interactions)

为了达到 S&F 的流畅体验，Client Agent 必须实现以下交互细节：

### 3.1 智能对比提示框 (Smart Comparison Tooltip) 【核心功能】
当玩家鼠标悬停（Hover）或手指长按（Touch）商店货架上的某件装备时，必须弹出提示框，且**必须与玩家身上同槽位的装备进行比对**。

*   **数值染色规则**：
    *   如果商店物品的某项属性 **高于** 当前装备，该数值显示为 **绿色 (#00FF00)**。
    *   如果 **低于** 当前装备，该数值显示为 **红色 (#FF0000)**。
    *   如果 **等于**，显示为默认颜色（如白色或灰色）。
*   **综合强度指示器 (Power Indicator)**：
    *   在 Tooltip 的最下方，根据属性总和的差值，显示一个醒目的指示图标。
    *   `▲ [绿色箭头]` 表示整体提升。
    *   `▼ [红色箭头]` 表示整体下降。

### 3.2 拖拽购买与穿戴 (Drag & Drop)
*   **交互方式**：支持将物品从商店货架直接拖拽到左侧人物相应的装备槽位上。
*   **逻辑触发**：拖拽松手（Drop）时，若槽位匹配且金钱足够，前端直接发送 `/api/action` 请求（包含购买+穿戴操作）。
*   **双击购买 (Double Click)**：作为备用交互，双击商店物品直接购买至背囊（Inventory）。

## 4. 动效与音效规格 (Animations & Audio)

### 4.1 UI 动效 (UI Animations)
*   **刷新动效 (Refresh Flip)**：点击刷新按钮时，货架上的 6 个物品不应该瞬间切换。应该有一个“翻牌”或“卡牌旋转”的 CSS/Tween 动画（持续约 0.3s）。
*   **购买反馈 (Purchase Feedback)**：
    *   成功购买后，被买走的槽位显示一个“已售空”的占位符。
    *   触发金币飞向右上角（扣除金钱）的粒子特效。
*   **换装震动 (Equip Shake)**：装备穿上时，左侧的角色立绘或对应槽位产生轻微的缩放震动（Scale 1.0 -> 1.1 -> 1.0），增强打击感。

### 4.2 音效 (SFX)
*   **Hover 音效**：鼠标滑过装备时的轻微“唰唰”声（类似纸张摩擦）。
*   **购买音效**：清脆的古代铜钱碰撞声（叮当声）。
*   **装备音效**：
    *   穿戴金属护甲/武器：沉重的金属撞击声。
    *   穿戴布衣/首饰：清脆的玉石声或布料摩擦声。
*   **刷新音效**：类似洗牌或木牌翻转的声音。
