# Shakes and Fidget 复刻版变现方案建议

**文档编号**：SF_MON_08
**版本**：1.0
**日期**：2026-04-29
**文档性质**：内部策划参考

---

## 摘要

本方案针对 Shakes and Fidget 复刻版的国内变现策略提出系统性建议。核心思路是：以 S&F 原版"低度 P2W + 外观付费"的轻量化变现模型为主框架，叠加月卡/通行证等国内常见付费入口，在保证口碑的前提下提升 ARPU。方案不引入抽卡/开箱机制，以合规性和长期运营健康度为核心取舍标准。

---

## 1. 核心变现模型选择

### 1.1 方案A：延续低度 P2W 模型（推荐）

沿用 S&F 原版的核心逻辑——付费主要购买速度/便利性，不直接购买战斗力。玩家可以通过肝（时间投入）获得几乎所有游戏内容，付费仅作加速和外观之用。

**优势**：
- 用户口碑根基好。S&F 之所以在欧美有十多年生命周期，正是因为这套模型。移植到国内，核心玩家圈层（TapTap/好游快爆上的硬核用户）对无 P2W 的游戏有明确偏好。
- 长期留存高。玩家没有"不充钱就被碾压"的挫败感，流失率低，LTV 曲线更健康。
- 口碑传播效应强。S&F 原版在玩家社区有大量正面讨论，复刻版可复用这一品牌资产。

**劣势**：
- ARPU 偏低。根据同类产品数据，低度 P2W 模型的月 ARPU 通常在 20-50 元区间，显著低于国内主流手游。
- 短期收入表现弱。对投资人/KPI 汇报不友好，需要预设合理的预期管理。

**适用判断**：如果目标是 3-5 年以上的长线运营，且愿意以口碑换长期收入，推荐采用。

### 1.2 方案B：加入订阅制/月卡（推荐辅助）

在低度 P2W 基础上叠加月卡/通行证体系。月卡在 Idle 类游戏中天然适配——玩家离线期间游戏自动运行，月卡提供的每日奖励在玩家上线时"等待"他们，形成正向循环。

**月卡核心设计（¥30/月）**：
- 每日登录领取 20 高级货币，30 天累计 600 货币
- 相比直接购买，30 天月卡 ROI 约 200%，定价有竞争力
- 附加效果：月卡期间坐骑租赁 9 折、啤酒冷却时间缩短

**通行证核心设计（可选，¥68/赛季）**：
- 赛季周期 42 天（约 6 周）
- 双轨制：免费玩家可肝通行证进度，付费解锁高级奖励轨道
- 高级轨道奖励：限定坐骑皮肤、成就称号、公会旗帜、头像框
- 不提供任何战斗力加成，仅外观/身份标识

**优势**：
- 稳定月收入来源。订阅制用户有惯性，续订率通常高于单次购买。
- 对轻度付费玩家友好。月卡 ¥30/月在可接受范围内，不伤害公平感。
- 通行证创造"赛季目标"，提升 DAU 和赛季活跃度。

**劣势**：
- 与 S&F"免费可得一切"的核心理念存在张力。需要在 UI 和文案上做好叙事，避免玩家感觉"被迫付费"。
- 增加开发和运营复杂度。

### 1.3 方案C：中度 P2W 模型（不推荐）

在速度便利基础上增加少量付费战斗力要素（如：装备强化成功率道具、宝石镶嵌槽解锁等）。

**优势**：短期 ARPU 提升明显。
**劣势**：直接损害 S&F 品牌核心价值，引来核心玩家差评，与长线运营目标背道而驰。除非商业压力极大，否则不建议。

### 1.4 推荐策略：方案A为主 + 方案B辅助

低度 P2W 作为变现底座，月卡作为稳定付费入口，通行证作为进阶变现手段。三者叠加预计可将月 ARPU 提升至 40-80 元区间，同时保持较好的口碑基本面。

## 2. 高级货币设计

### 2.1 货币命名与主题适配

S&F 原版使用"蘑菇"（Mushroom）作为高级货币，名称轻松有趣，与游戏的奇幻冒险主题契合。复刻版建议保持这一命名逻辑的一致性。

**推荐命名方案**：

| 方案 | 名称 | 风格 | 适配度 |
|------|------|------|--------|
| 方案1 | 灵玉 | 仙侠古风 | 低，与西式奇幻世界观冲突 |
| 方案2 | 星尘 | 奇幻魔法 | 中，契合但偏软 |
| 方案3 | 金币（Gold） | 经典奇幻 | 高，与 S&F 一脉相承 |
| 方案4 | 魔晶 | 魔法水晶 | 高，契合战斗与冒险主题 |
| 方案5 | 龙币 | 东方奇幻 | 中，略带东方色彩 |

**建议采用"魔晶"（Magic Crystal）**——既保留了 S&F 的奇幻基调，又在国内玩家认知中有明确的"付费货币"属性暗示。UI 中可设计为紫色水晶图标，与普通金币形成视觉区分。

**命名原则**：
- 轻松有趣，不过于严肃
- 符合西式奇幻/冒险世界观
- 国内玩家接受度高，无歧义
- 不与装备/道具名称混淆

### 2.2 获取途径本地化调整

**保留项（S&F 原版已有）**：
- 每日登录奖励（建议调整为递减式，激励连续登录）
- 任务/副本掉落
- 远征收益
- 节日活动

**调整项**：
- Offer Wall（海外广告墙）→ 替换为激励视频广告
  - 国内用户对 Offer Wall 认知度低，转化差
  - 激励视频（看广告换资源）是国内成熟模式，用户接受度高
  - 实现方式：每日首次观看激励视频获得双倍奖励，每日上限 3 次

**新增项**：
- 连续签到日历（7 天周期）
  - D1: 50 金币
  - D2: 100 金币
  - D3: 啤酒 x1
  - D4: 150 金币
  - D5: 坐骑租赁券 x1
  - D6: 200 金币
  - D7: 限定头像框（签到专属）
  - 中断则重置
- 每日活跃任务（类似国内手游日常）
  - 完成 3 场战斗：+20 金币
  - 通关一次副本：+30 金币
  - 参与公会战：+50 金币
- 分享邀请奖励
  - 邀请好友成功注册：双方各得 100 金币

### 2.3 消耗场景保留与扩展

**保留项（S&F 原版核心付费点）**：

| 消耗场景 | 描述 | 付费逻辑 |
|----------|------|----------|
| 坐骑租赁 | 租用时限性强力坐骑（属性加成） | 核心变现点，¥30-128 不等 |
| 啤酒 | 恢复"口渴值"，跳过等待 | ¥6-30/次 |
| 幸运轮盘 | 消耗金币抽奖（小额，1-50 金币/次） | 低门槛付费入口 |
| 外观购买 | 装备皮肤、角色皮肤 | 外观党付费 |
| 加速道具 | 建造/任务完成加速 | 功能性付费 |

**扩展考虑项**：

| 新增场景 | 描述 | 付费逻辑 |
|----------|------|----------|
| 月卡专属特权 | 月卡期间额外每日任务、专属折扣 | 月卡用户留存手段 |
| 公会旗帜/皮肤 | 公会可见的外观定制 | 公会付费（公会战激励） |
| 头像框/称号 | 社交身份展示 | 低单价外观付费 |
| 体力/资源背包扩展 | 增加资源存储上限 | 便利性付费 |

**不推荐新增**：
- 直接购买装备（触碰 P2W 红线）
- 强化成功率付费道具（影响平衡性）
- 抽卡/开箱系统（合规风险 + 口碑风险）

## 3. 礼包与促销本地化

### 3.1 国内定价策略

参考国内主流手游定价体系，结合游戏内容深度，建议以下档位：

```
¥6   ≈ 50 魔晶（破冰档，首充奖励）
¥30  ≈ 300 魔晶（日常档）
¥68  ≈ 700 魔晶（热门档）
¥128 ≈ 1400 魔晶（高价值档）
¥328 ≈ 3800 魔晶（重氪档）
¥648 ≈ 8000 魔晶（最高档）
```

**定价逻辑说明**：
- ¥6 档：对标国内"六元党"习惯，降低首次付费门槛
- ¥30 档：月卡价格锚点，视觉上"一个月月卡"
- ¥68 档：国内玩家心理舒适区，高性价比
- ¥128/¥328 档：阶梯式付费能力适配
- ¥648 档：国内最高单笔付费档位，保留即可

**魔晶与购买力的换算基准**：
- 坐骑租赁：30-128 魔晶/次
- 啤酒：6 魔晶/次
- 幸运轮盘：1-50 魔晶/次
- 外观皮肤：30-200 魔晶/件

### 3.2 首充/六元党引导设计

六元党是中国手游特有的高转化、高粘性付费群体。设计要点在于：价值感强、立即见效、无后悔感。

**首充礼包设计**：
- 价格：¥6
- 内容：100 魔晶 + 限时坐骑体验券（7 天）× 1 + 首充专属称号
- 触发时机：玩家首次达到 10 级时弹出（已体验基础游戏内容，不会感觉被强迫）
- 文案方向：不强调"便宜"，强调"超值"。避免"只要六元"等低价营销话术，改用"获得价值 ¥30 的开荒大礼包"。

**六元党用户特征**：
- 付费频次高但单笔低
- 对游戏内容消耗快，需要持续新内容
- 社交传播意愿强（"我充了六块钱也很强"心态）

**运营策略**：首充解锁后，持续推送 ¥30 以内的小额礼包，利用六元党"已经付过钱就不怕再付"的心理惯性。

### 3.3 月卡/通行证国内模式

**月卡（推荐优先上线）**：

| 项目 | 内容 |
|------|------|
| 价格 | ¥30/月 |
| 每日领取 | 20 魔晶 + 月卡专属任务（额外 +10 魔晶/日） |
| 30 天总回报 | 900 魔晶（相当于 ¥68 档购买量） |
| 附加权益 | 坐骑租赁 9 折、啤酒冷却 -30 秒、专属月卡标识 |
| 付费入口 | 首页常驻入口 + 首次 10 级引导 |

**通行证（Phase 2 上线）**：

| 项目 | 内容 |
|------|------|
| 价格 | ¥68/赛季 |
| 赛季周期 | 42 天 |
| 等级上限 | 50 级 |
| 免费轨道奖励 | 魔晶、啤酒、材料、基础外观 |
| 付费轨道奖励 | 限定坐骑皮肤、称号、头像框、公会旗帜 |
| 战力加成 | 无（严格限制为外观/身份奖励） |
| 肝度要求 | 免费玩家约需 2 周可肝满，付费玩家可跳级 |

## 4. 运营活动适配

### 4.1 国内节日活动替换

| 原 S&F 活动 | 替换为国内活动 | 建议时间 | 活动类型 |
|-------------|---------------|----------|----------|
| 黑色星期五 | 双 11 大促 | 11 月初 | 限定礼包 5-7 折 |
| 圣诞节 | 春节活动 | 农历新年（1-2 月）| 登录奖励 + 限定坐骑 |
| 复活节 | 端午/清明活动 | 4 月 | 粽子/艾草主题外观 |
| 万圣节 | 万圣节保留 + 中元节弱化 | 10 月底 | 恐怖主题副本 |
| 夏日活动 | 暑期活动 | 7-8 月 | 登录奖励 + 限定皮肤 |
| 周年庆 | 周年庆保留 | 上线纪念日 | 全服庆典 + 限定奖励 |

**节日活动设计原则**：
- 活动期间登录即送基础奖励，维护 DAU
- 限定外观（坐骑/皮肤）作为核心活动奖励，驱动参与
- 避免限时过短（玩家来不及参与）和过长（失去稀缺感）

### 4.2 版更活动节奏

每次大版本更新（新增系统/新章节）配套以下活动：

- **新功能解锁礼包**（¥30 档）：上线首周限时购买，提供新系统所需核心道具
- **版本纪念活动**（免费）：全服完成特定目标解锁奖励，如"7 天内全服击杀 BOSS 100 万次 → 全服发放 50 魔晶"
- **回归玩家活动**：版本更新后 7 天内登录的流失玩家，给予回归礼包（¥6 首充优惠 + 回归专属道具）

### 4.3 公会战付费激励

公会战是 S&F 核心玩法之一，可设计以下付费点：

- **公会赛季排行榜奖励**：按赛季排名发放限定称号和公会旗帜（外观付费）
- **公会战消耗道具**：增援卷轴、城墙修复道具等（小额日常付费）
- **公会红包功能**：允许玩家向公会成员赠送魔晶（社交付费，非强制）
- **公会升级加速**：加速公会建筑升级（非核心付费点，轻度可选）

## 5. 合规与风险控制

### 5.1 国内监管要求

**游戏版号**：
- 复刻版必须取得国内游戏版号方可商业化运营
- 审批周期通常 3-6 个月，需提前规划
- 建议同步准备 Windows PC 版和移动版的版号申请

**实名认证与防沉迷**：
- 接入国家实名认证系统（公安库校验）
- 未成年用户（<18 岁）执行防沉迷限制：
  - 周五/六/日及法定节假日：每日 20:00-21:00 可玩 1 小时
  - 工作日：禁止游戏
- 付费限制：未实名用户和未成年用户单次/每月付费上限

**游戏适龄提示**：
- 根据游戏内容（轻微暴力、饮酒元素），建议申请 12+ 适龄提示
- 部分内容（啤酒饮酒文化）需评估是否影响适龄评级

### 5.2 抽卡/开箱合规处理

S&F 原版无抽卡/开箱机制——这是复刻版的合规优势。

**如果未来考虑引入类似机制**：
- 必须公示抽卡概率（明确标注各物品概率）
- 设置抽卡次数上限（每日/每周）
- 禁止未成年人参与
- 需在版号申请时单独说明

**当前建议**：不引入抽卡/开箱，继续以直购礼包为主变现方式。

### 5.3 未成年人保护

| 措施 | 具体内容 |
|------|----------|
| 消费限额 | 未成年用户单次充值不超过 ¥50，月累计不超过 ¥200 |
| 付费提醒 | 累计消费达到 ¥200 时弹出"理性消费"提示 |
| 家长监护 | 提供家长绑定/查询入口 |
| 禁止诱导 | 禁止"首充特惠仅限今日"等紧迫感话术面向未成年用户 |
| 消费冷静期 | 大额充值（>¥100）增加二次确认 |

### 5.4 虚拟货币合规

- 魔晶不得反向兑换法定货币
- 魔晶不得在游戏外流通/交易
- 明确虚拟物品所有权归玩家，但公司保留合理运营调整权
- 退款政策：参照国内主流做法，未消耗虚拟货币可申请退款（需实名验证）

## 6. 实施路线图

### Phase 1：基础变现（Alpha/Beta 测试期）

**目标**：验证核心付费点可行性，建立基础 ARPU 基线

**上线内容**：
- 高级货币系统（魔晶）
- 坐骑租赁（核心付费点）
- 啤酒/口渴值扩充
- 幸运轮盘
- 首充礼包（¥6）
- 连续签到日历
- 激励视频广告

**关键指标**：
- 付费转化率目标：3-5%
- 首充 ARPU：¥8-15
- 月 ARPU 目标：¥15-25

### Phase 2：活动体系（正式上线后 1-3 个月）

**目标**：建立稳定的活动运营节奏，提升 DAU 和付费频次

**上线内容**：
- 月卡系统（¥30）
- 周末增益活动循环（每周五六日双倍奖励）
- 节日活动（春节、暑期）
- 里程碑礼包链（累计充值梯度奖励）
- 每日活跃任务

**关键指标**：
- 月 ARPU 目标：¥30-50
- 月付费率目标：8-15%

### Phase 3：高级变现（上线后 3-6 个月）

**目标**：拓展高价值用户付费深度，建立赛季内容体系

**上线内容**：
- 通行证系统（¥68/赛季）
- 大型赛季活动（地狱电梯高难度赛季、世界 BOSS 挑战）
- 限定节日礼包
- 促销折扣体系（限时打折）
- 公会战付费道具

**关键指标**：
- 月 ARPU 目标：¥50-80
- LTV 30 日目标：¥40-60

### Phase 4：优化迭代（持续运营期）

**目标**：数据驱动持续优化，提高变现效率

**工作内容**：
- A/B 测试付费转化漏斗（首充弹窗时机、文案、定价）
- 数据驱动的礼包内容优化（根据道具消耗数据调整礼包组合）
- 活动节奏调优（基于参与率和付费转化数据）
- ARPU/LTV 深度分析，识别高价值用户特征

## 7. 关键风险与缓解

### 7.1 风险清单

| 风险类别 | 具体风险 | 严重程度 |
|----------|----------|----------|
| 收入风险 | 付费点过少导致 ARPU 显著低于市场水平 | 高 |
| 口碑风险 | 过度 FOMO 设计导致玩家反感 | 中 |
| 运营风险 | 活动频率不当导致玩家疲劳或无感 | 中 |
| 合规风险 | 版号申请延误或内容不合规 | 高 |
| 用户风险 | 未成年人付费争议/投诉 | 高 |

### 7.2 缓解策略

**付费点过少（ARPU 不足）**：
- Phase 1 验证后，根据数据快速补充月卡和活动礼包
- 建立"功能性外观"付费场景（不影响战力但满足炫耀需求）
- 监控 ARPU 趋势，Phase 3 前完成必要调整

**口碑恶化（FOMO 过重）**：
- 所有限时活动提供足够的参与窗口（至少 7 天）
- 绝不使用"最后一次机会""即将绝版"等焦虑营销
- 定期复刻高人气限定外观（让错过玩家有机会获得）
- 设立玩家反馈渠道，及时响应差评

**活动频率失衡**：
- 建立活动日历，提前 2 周预告
- 活动期间监控参与率，低于 30% 立即分析原因
- 避免连续两个高强度活动，中间安排"休养期"

**版号合规风险**：
- 项目启动即启动版号申请流程
- 内容设计阶段与版号代理保持沟通，预判合规风险
- 提前准备适龄提示申请材料

**未成年人付费**：
- 技术层面强制实名认证
- 运营层面：月卡首充引导弹窗增加年龄确认步骤
- 客服层面：建立未成年人退款快速处理通道

## 8. 总结与建议

### 核心结论

1. **低度 P2W + 外观付费是复刻版的最优变现底座**。S&F 的品牌价值和长期生命力来源于这套模型，改动风险远大于收益。

2. **月卡是必须优先上线的变现入口**。月卡在 Idle 游戏中转化效率高，与游戏离线收益机制天然契合，且不损害公平性。建议正式上线前完成开发。

3. **通行证是可选但值得投入的高级变现手段**。通行证创造赛季目标，提升 DAU 和付费深度，但需要额外的美术和运营投入。建议 Phase 3 上线。

4. **不引入抽卡/开箱**。S&F 没有这套机制，复刻版也不需要。合规成本和口碑风险不成比例。

5. **合规先行**。版号、防沉迷、实名认证必须在商业化上线前完成。合规问题一旦爆发，修复成本远高于预防成本。
