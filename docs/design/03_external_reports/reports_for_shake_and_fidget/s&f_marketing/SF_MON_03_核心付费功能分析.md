## 摘要

Shakes and Fidget 采用**混合变现模型**，以坐骑系统为最大付费杠杆，以日常啤酒循环为稳定现金流来源，辅以幸运轮盘、加速功能、外观定制等多元化付费点。本文档系统梳理各付费功能的定价、效果、策略设计，并按付费意愿强度、付费频率、玩家感知价值三个维度进行综合评估。

#### 狮鹫为何是"必买"坐骑

**核心逻辑**：狮鹫使任务次数在14天内翻倍

假设玩家每天可完成 N 次任务：
- 无坐骑：14天 = 14N 次任务
- 狮鹫加成后：14天 = 28N 次任务

**翻倍带来的直接收益**：
1. **经验值翻倍** → 角色升级速度翻倍
2. **装备掉落翻倍** → 稀有装备获取概率线性提升
3. **蘑菇掉落概率翻倍** → 高价值道具获取机会翻倍
4. **金币收入翻倍** → 强化材料购买力提升

**边际成本分析**：

| 对比项 | 狮鹫 | 老虎 | 狮鹫 vs 老虎增量收益 |
|-------|-----|-----|---------------------|
| 价格 | 25蘑菇 | 10蘑菇 | 多花15蘑菇 |
| 任务加速 | 100% | 25% | +75% |
| 持续时间 | 14天 | 14天 | 相同 |

狮鹫相比老虎的增量成本为15蘑菇，但增量收益（任务次数提升75%）远超边际价格，是**性价比最高的坐骑**。🅰️官方

**口渴值上限构成**：

| 来源 | 口渴值 | 备注 |
|-----|-------|------|

**数据缺口**：部分来源提及"蘑菇啤酒最多20杯"，但实际测试显示蘑菇啤酒与免费啤酒共享同一口渴值池，而非叠加。🅳推测

### 2.2 啤酒获取来源

| 啤酒类型 | 获取量 | 成本 | 口渴恢复 | 数据来源 |

| 蘑菇啤酒 | 每杯1蘑菇 | 1蘑菇 | 20点/杯 | 🅰️官方 |
| 任务奖励 | 波动 | 0 | 20-40点 | 🅱️社区 |

### 2.3 口渴值扩展的经济学分析

**日均口渴消耗场景**：

| 场景 | 口渴消耗 | 免费啤酒覆盖 | 需蘑菇补充 | 蘑菇日消耗 |
|-----|---------|-------------|-----------|---------|
| 轻度玩家 | 100 | 100 | 0 | 0 |
| 中度玩家 | 200 | 200 | 0 | 0 |
| 重度玩家 | 300 | 200 | 100 | 5蘑菇 |
| 硬核玩家 | 420 | 200 | 220 | 11蘑菇 |

**日付费区间**：0-11蘑菇/天

**月付费估算**：
- 中度付费：150蘑菇/月
- 重度付费：300蘑菇/月 🅳推测

### 2.4 酒馆经济学核心洞察

1. **免费玩家与付费玩家的分水岭**：口渴值超过200点时，付费行为开始产生
2. **边际成本递减**：蘑菇啤酒按杯购买，无批量折扣，维持高活跃度的成本线性增长
3. **日活驱动设计**：免费啤酒每日重置，激励玩家每日登录
4. **"刚好够用"陷阱**：如果游戏节奏设计为每日消耗接近210口渴值，玩家会感到"只差一点"，从而触发小额付费

## 3. 幸运轮盘 Dr. Abawuwu

### 3.1 轮盘奖励池（基于社区逆向）

| 奖励类型 | 出现概率 | 估算价值 |
|---------|---------|---------|
| 小额金币 | ~35% | 50-200金币 |
| 中额金币 | ~25% | 500-1000金币 |
| 经验卷轴 | ~15% | 100-500经验 |
| 蘑菇 | ~5% | 1-3蘑菇 |
| 稀有材料 | ~10% | 价值不等 |
| 空奖/谢谢参与 | ~10% | 0 |

*注：以上概率为社区逆向估算，未获官方证实。* 🅲逆向 🅳推测

### 3.2 轮盘机制设计

**每日参与结构**：
- 第1次：免费
- 第2-20次：每次消耗1蘑菇

**日均固定消耗**：19蘑菇（无论运气好坏）

**总日消耗**：19蘑菇（基于轮盘19次 × 1蘑菇）

### 3.3 变现效率 vs 玩家体验的平衡

| 分析维度 | 评估 |
|---------|------|
| 变现效率 | 高（固定日消耗，形成稳定预期） |
| 玩家接受度 | 中高（首次免费降低进入门槛） |
| 期望值管理 | 好（玩家知道最多19蘑菇） |
| 付费感知价值 | 低（大部分奖励为低价值道具） |

**关键洞察**：轮盘的核心价值不在于奖励本身，而在于：
1. 创造"每日仪式感"
2. 消耗玩家积累的蘑菇库存
3. 提供"再来一次"的赌博式体验

### 3.4 轮盘月消耗估算

| 参与模式 | 月蘑菇消耗 |
|---------|-----------|
| 每日20次完整参与 | 570蘑菇/月 |
| 隔日参与 | 285蘑菇/月 |
| 仅免费首抽 | 0 |

## 9. 核心结论

### 9.1 变现设计核心逻辑

Shakes and Fidget 的变现设计遵循以下核心原则：

1. **"双倍体验"定价锚点**：狮鹫坐骑以25蘑菇/14天建立价值基准，所有其他付费点的定价逻辑都以此为参照
2. **时间货币化**：游戏内所有"等待时间"都可以用蘑菇跳过，蘑菇=时间
3. **零氪玩家留存设计**：通过"可实现的目标"（攒25蘑菇买狮鹫）维持免费玩家活跃度
4. **小额高频优先**：日均小额付费（轮盘+啤酒）比单次大额付费更稳定

### 9.2 关键数字总结

| 指标 | 数值 |
|-----|------|
| 核心坐骑（狮鹫）价格 | 25蘑菇/14天 |
| 日均付费区间 | 0-30蘑菇 |
| 月均付费区间 | 0-900蘑菇 |
| 免费玩家日均蘑菇获取 | 0.5-1蘑菇 |
| 攒够狮鹫所需时间（零氪） | 30-50天 |
