# 第一部分：竞技场系统

## 1. 竞技场系统概述

🅰️ **A级**（官方帮助中心）

### 1.1 系统定位

竞技场（Arena）是 SF Game 的**核心 PvP 系统**：
- 玩家与其他玩家（的战斗镜像数据）对战
- 通过赢取战斗积累**荣誉值（Honor）**，提升全服排名
- 荣誉排名影响暴击伤害倍率（间接影响战斗强度）
- 每日登录必做内容之一，是稳定的金币来源

### 1.2 竞技场设计哲学

| 设计目标 | 实现方式 |
|---------|---------|
| 玩家互动感 | 与真实玩家数据对战（虽然是镜像）|
| 持续进步感 | 荣誉值与排名可见，目标清晰 |
| 每日回归动力 | 每日次数限制 + 荣誉衰减机制 |
| 平衡性 | 从同区间荣誉对手中匹配 |

## 2. 竞技场对手匹配机制

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 2.1 匹配逻辑

- 从**名人堂（Hall of Fame）**随机抽取3名玩家作为对手候选
- 候选对手来自与自身荣誉排名**相近的范围**（非完全随机）
- 玩家在3个候选中**手动选择一个**发起战斗

### 2.2 匹配范围规则

🅱️ **B级**（社区整理）

| 规则 | 说明 |
|------|------|
| 荣誉排名越高，候选对手越强 | 越靠近排行榜前列，对手难度越大 |
| 候选来自名人堂可见的玩家 | 只能挑战已经在名人堂中的玩家 |
| 可看到对手角色信息 | 等级、职业、荣誉值均可见，辅助选择 |

### 2.3 对手选择策略

🅱️ **B级**（玩家社区）

- 选择**荣誉值接近但略低**于自己的对手（胜率高，荣誉获取稳定）
- 选择**职业相性好**的对手（如法师克制高护甲职业）
- 避免选择比自己等级高很多的对手（属性差过大）

## 3. 荣誉（Honor）系统

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 3.1 荣誉值规则

| 参数 | 说明 |
|------|------|
| **胜利获得** | 根据对手荣誉值计算，对手越高获得越多 |
| **失败扣除** | 根据自身荣誉值扣除 |
| **初始荣誉** | 角色创建时拥有初始荣誉值（约100点）|
| **荣誉下限** | 不会扣为负数（有下限保护，通常为0）|

### 3.2 荣誉值变化公式

🅲 **C级**（sf-tools 荣誉计算）

```
胜利获得荣誉 = 基础荣誉增量 × f(对手荣誉排名 / 自身荣誉排名)
失败扣除荣誉 = 基础荣誉减量 × g(自身荣誉排名)
```

> 🗒️ 精确公式未能完全逆向，以下为社区估算（B级）：

🅱️ **B级**（社区估算）

- **击败荣誉值更高的对手**：获得荣誉 ×1.5~2倍
- **击败荣誉值相当的对手**：获得荣誉 ×1倍
- **击败荣誉值远低的对手**：获得荣誉 ×0.1~0.5倍（收益极低）
- **失败**：扣除自身荣誉约 10~20点（视自身排名）

### 3.3 荣誉对战斗数值的影响

🅲 **C级**（sf-tools 战斗公式中的荣誉因子）

荣誉值差影响**暴击伤害倍率**：

```
暴击伤害倍率加成 = 0.11 × (自身竞技场等级 - 目标竞技场等级)
```

- "竞技场等级"即荣誉排名对应的等级（排名越高，竞技场等级越高）
- 荣誉排名差每差1级，暴击倍率差 0.11
- 这意味着**高荣誉排名带来实质性战斗优势**

## 4. 竞技场战斗规则

🅰️ **A级**（官方帮助中心）+ 🅲 **C级**（sf-tools验证）

### 4.1 先攻规则

- 竞技场战斗：**荣誉值较高的玩家先攻**
- 荣誉相同时：随机决定

### 4.2 战斗使用数据

- 对手的战斗数据为**快照数据**（非实时同步）
- 对手可能当前不在线，攻击的是存储的角色镜像
- 角色在被挑战时不会知道（服务器侧处理）

### 4.3 战斗规则与标准战斗相同

- 使用相同的 HP / 护甲 / 伤害 / 暴击 / 怒气公式（见战斗系统文档）
- 不同：荣誉差影响暴击倍率（见 §3.3）

## 7. 名人堂（Hall of Fame）

🅰️ **A级**（官方帮助中心）

### 7.1 名人堂功能

- 展示全服玩家的**荣誉排名列表**
- 每个玩家条目包含：等级、职业、种族、荣誉值、公会名
- 用于竞技场的**对手候选来源**

### 7.2 进入名人堂条件

🅱️ **B级**（社区整理）

- 新角色创建后，荣誉值达到一定阈值即自动出现在名人堂
- 具体阈值可能随服务器总玩家数变化

### 7.3 名人堂在系统中的数据流

```
名人堂数据流：
玩家战斗结果 → 荣誉值更新 → 名人堂排名实时更新
↓
竞技场匹配 → 从名人堂中筛选候选对手（玩家荣誉±N范围内）
↓
玩家选择对手 → 战斗计算 → 结果更新荣誉
```

# 第二部分：堡垒系统

## 8. 堡垒系统概述

🅰️ **A级**（官方帮助中心）+ 🅱️ **B级**（number13.de 攻略）

### 8.1 系统定位

堡垒（Fortress）系统是一套**城市建设/资源管理**子游戏：
- 解锁等级：**25级**
- 为角色提供多种**永久增益**（学院EXP、宝石矿、金币坑等）
- 构建玩家间的**攻防互动**（资源掠夺机制）
- 中期后成为重要的**被动资源产出**来源

### 8.2 堡垒设计哲学

| 设计目标 | 实现方式 |
|---------|---------|
| 长期持续目标 | 建筑升级周期长（数小时~数天）|
| 资源竞争 | 玩家间可互相攻击掠夺资源 |
| 安全保障 | 前48小时保护期，防御建筑降低损失 |
| 被动成长 | 各建筑提供持续产出，登录频率不影响被动收益 |

---

| 建筑 | 英文 | 最高等级 | 功能 |

- 例如主建筑10级，则其余建筑最高10级
- 升级顺序应优先升主建筑 → 再升其他建筑

## 10. 资源系统

🅰️ **A级**（官方帮助中心）

### 10.1 两种堡垒资源

| 资源 | 来源建筑 | 用途 |
|------|---------|------|
| **木材（Wood）** | 伐木小屋 | 建筑建造/升级的主要消耗 |
| **石材（Stone）** | 采石场 | 建筑建造/升级的主要消耗 |

### 10.2 资源产出速率

🅱️ **B级**（number13.de 实测数据）

| 建筑等级 | 木材/石材产出（每小时，估算）|
|---------|---------------------------|
| 1级 | ~2~5单位/小时 |
| 5级 | ~20~40单位/小时 |
| 10级 | ~100~200单位/小时 |
| 20级（满）| ~500~1000单位/小时 |

> 🗒️ 以上为估算数值（B级），具体需实测验证。

### 10.3 资源存储上限

🅰️ **A级**（官方帮助中心）

```
资源存储上限 = f(主建筑等级)
```

- 主建筑每升1级，存储上限显著提升
- 超出上限的产出**会溢出丢失**，需定期登录收取

### 10.4 后期资源主要来源

🅰️ **A级**（官方帮助中心）

> 后期资源主要靠**攻击掠夺**其他玩家获得，而非自产  
> 自产速率有上限，而掠夺量远超自产

## 11. 堡垒攻防机制

🅰️ **A级**（官方帮助中心）

### 11.1 攻击流程

```
发起攻击 → 选择目标玩家堡垒
         → 出兵（消耗兵营中的士兵）
         → 攻城（士兵 vs 对方防御力量：弓箭手+法师+防御工事）
         → 胜利 → 掠夺木材/石材
         → 失败 → 无收益
```

### 11.2 防御组成

| 防御组件 | 说明 |
|---------|------|
| **弓箭手** | 来自弓箭手公会，是主要防御力量 |
| **法师** | 来自法师塔，特殊攻击效果 |
| **防御工事** | 提供被动防御加成（减少伤亡）|
| **工人宿舍** | 减少被攻击时的资源损失量 |

### 11.3 保护期规则

🅰️ **A级**（官方帮助中心）

- 新建堡垒主建筑后，**前48小时无法被掠夺**
- 保护期结束后，其他玩家可自由发起攻击

### 11.4 掠夺量计算

🅱️ **B级**（社区整理）

```
可掠夺资源量 ≈ 目标玩家当前储存量 × 掠夺比例
```

- 掠夺比例受攻击方兵力强度和防御方工人宿舍等级影响
- 工人宿舍等级越高，每次被掠夺损失越少

## 13. 前30级堡垒发展规划

🅱️ **B级**（玩家社区最优策略）

### 13.1 解锁时（25级）的推荐建造顺序

```
优先级排序（25~30级阶段）：
1. 主建筑（Main Building）→ 升到3~5级（解锁其他建筑等级上限）
2. 采石场 + 伐木小屋 → 各升1~3级（建立资源循环）
3. 工人宿舍 → 升1~3级（缩短后续建造时间）
4. 学院 → 升1~3级（每日被动经验）
5. 金库 → 升1~3级（+3背包格，性价比高）
```

### 13.2 25~30级阶段目标

| 目标 | 预期收益 |
|------|---------|
| 主建筑 5级 | 解锁其他建筑升至5级 |
| 学院 3级 | 每日额外约1/3任务量的经验 |
| 宝石矿 1级 | 开始宝石积累，为装备宝石槽做准备 |
| 金库 3级 | +3背包格，减少装备满溢 |

### 13.3 不应该优先建的内容

🅱️ **B级**（玩家社区建议）

- **不要过早投入军事建筑**（兵营/弓箭手/法师塔）：前期资源稀缺，战斗收益不明显
- **金币坑可稍后建**：前期资源应优先扩大建筑规模
- **锻炉可以最后建**：前期军队规模小，升级意义不大

## 14. 复刻实现要点

🅳 **D级**（开发建议）

### 14.1 竞技场系统数据结构

```javascript
// 竞技场系统
class ArenaSystem {
  constructor(player) {
    this.player = player;
    this.dailyAttacks = 0;
    this.MAX_DAILY_ATTACKS = 10; // 基础10次/天
    this.lastResetDate = new Date().toDateString();
  }
  
  // 重置每日次数（每天凌晨）
  checkDailyReset() {
    const today = new Date().toDateString();
    if (today !== this.lastResetDate) {
      this.dailyAttacks = 0;
      this.lastResetDate = today;
    }
  }
  
  // 获取3个候选对手
  getCandidates(hallOfFame) {
    // 在自身荣誉值范围内取样
    const honorRange = [this.player.honor * 0.8, this.player.honor * 1.3];
    const eligiblePlayers = hallOfFame.filter(p => 
      p.id !== this.player.id &&
      p.honor >= honorRange[0] && 
      p.honor <= honorRange[1]
    );
    
    // 随机取3个
    return this.shuffleArray(eligiblePlayers).slice(0, 3);
  }
  
  // 发起竞技场战斗
  attackPlayer(target) {
    this.checkDailyReset();
    
    if (this.dailyAttacks >= this.MAX_DAILY_ATTACKS) {
      return { error: '今日竞技场次数已用尽' };
    }
    
    // 先攻：荣誉高的先攻
    const attackerFirst = this.player.honor >= target.honor;
    const [attacker, defender] = attackerFirst 
      ? [this.player, target] 
      : [target, this.player];
    
    const battle = new BattleSimulator(attacker, defender);
    const result = battle.run();
    
    this.dailyAttacks++;
    
    const playerWins = (attackerFirst && result === 'attacker_wins') || 
                       (!attackerFirst && result === 'defender_wins');
    
    // 更新荣誉值
    if (playerWins) {
      const honorGain = this.calculateHonorGain(target.honor);
      this.player.honor += honorGain;
      return { result: 'win', honorGain };
    } else {
      const honorLoss = this.calculateHonorLoss();
      this.player.honor = Math.max(0, this.player.honor - honorLoss);
      return { result: 'lose', honorLoss };
    }
  }
  
  // 荣誉增益计算（B级估算）
  calculateHonorGain(targetHonor) {
    const ratio = targetHonor / this.player.honor;
    if (ratio > 1.2) return Math.floor(20 * ratio);  // 挑战强敌，多荣誉
    if (ratio < 0.8) return 5;  // 挑战弱敌，少荣誉
    return 15; // 正常对手
  }
  
  calculateHonorLoss() {
    return Math.floor(this.player.honor * 0.02); // 大约2%荣誉
  }
}
```
