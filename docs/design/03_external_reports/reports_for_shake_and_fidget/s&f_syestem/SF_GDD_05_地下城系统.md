## 1. 系统概述与设计目标

🅰️ **A级**（官方帮助中心）

### 1.1 系统定位

地下城系统是 SF Game 的**核心 PvE 内容**，具体功能：

- 提供**高品质装备**（史诗/传奇品质的主要来源之一）
- 构建**里程碑式进度感**（解锁新地下城 = 明确成就感）
- 通过**地下城通关进度**解锁更多高级内容（高塔、影子世界）
- 形成每日登录目标之一（每日地下城重置）

### 1.2 设计目标矩阵

| 目标 | 实现方式 |
|------|---------|
| 进度里程碑 | 每个地下城对应特定解锁等级，等级越高内容越丰富 |
| 每日持续游玩 | 每日重置机制，优质奖励保持吸引力 |
| 挑战感 | 地下城敌人等级高于解锁门槛，需要较强装备才能通关 |
| 资源分层 | 特定地下城只产出特定材料（宝石矿/特殊装备），形成资源目的 |

## 3. 地下城结构与关卡设计

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 3.1 地下城内部结构

每个地下城由 **多个敌人顺序组成**：

```
地下城 #1（亵渎的地下墓穴）
├── Enemy 1（普通怪）
├── Enemy 2（普通怪）
├── Enemy 3（精英怪）
├── Enemy 4（普通怪）
├── Enemy 5（精英怪）
└── Enemy 6（BOSS）← 通关奖励在此
```

### 3.2 进入与退出规则

🅰️ **A级**（官方帮助中心）

| 规则 | 说明 |
|------|------|
| **进入方式** | 使用地下城钥匙进入（每把钥匙对应一次挑战机会）|
| **时间占用** | 进入地下城**消耗任务时间**（玩家进入地下城期间无法接任务）|
| **时长** | 通常为 1~2小时（根据地下城规模）|
| **失败处理** | 战斗失败后停在对应敌人处，下次进入从失败点继续（不重置进度）|
| **每日重置** | 每日凌晨（服务器时间）全部地下城进度重置 |
| **挑战限制** | 每日每个地下城只能完全通关1次（钥匙限制）|

### 3.3 战斗在地下城中的顺序规则

🅱️ **B级**（社区总结）

- 敌人**按固定顺序**挑战，不能跳过
- 打败一个敌人后，立即自动与下一个敌人战斗
- 每场战斗结束后，玩家 HP **完全恢复**（每场战斗相互独立）
- 连续战斗，直到失败或全部通关

> 🗒️ 这是一个关键机制：**每场战斗独立重置HP**，意味着"打不过Boss"是因为你的数值不够，而非前面战斗消耗过多。这简化了设计，让纯数值对比成为通关关键。

## 4. 地下城钥匙系统

🅰️ **A级**（官方帮助中心）

### 4.1 钥匙获取途径

| 获取途径 | 说明 |
|---------|------|
| **任务掉落** | 完成任务时低概率掉落对应地下城钥匙 |
| **宝石矿** | 堡垒宝石矿升级后可在挖掘中发现钥匙 |
| **魔法商店** | 高级地下城（#6+）钥匙可在魔法商店购买 |
| **武器商店** | 地下城 #9 钥匙可在武器商店购买 |
| **蘑菇购买** | 用蘑菇直接购买钥匙（高级货币兑换）|

### 4.2 钥匙存储限制

🅱️ **B级**（社区整理）

- 每种地下城钥匙有独立的**存储上限**（通常约1~5把）
- 持有上限后无法再获得对应钥匙（防止囤积）

### 4.3 前3个地下城钥匙获取策略

🅱️ **B级**（玩家社区建议）

- **地下城 #1/2/3**：均来自任务掉落，无法购买，需通过日常任务积累
- 建议每日保持任务效率，确保钥匙稳定积累
- 前期钥匙数量有限，建议在**主属性较高时**再使用（确保通关）

## 5. 战斗规则（地下城专属）

🅰️ **A级**（官方帮助中心）+ 🅲 **C级**（sf-tools 验证）

### 5.1 先攻规则

- 地下城战斗中，通常**玩家角色先攻**（不同于竞技场的荣誉先攻判定）
- 🅱️ 部分情况下 Boss 先攻（待确认）

### 5.2 每场战斗独立重置

- 玩家进入下一场战斗时，HP **完全恢复满值**
- 敌人之间**无数值关联**，完全独立战斗

### 5.3 同伴参与（Companions）

🅰️ **A级**（官方帮助中心）

- 解锁后（高塔及影子世界），同伴 Mark、Kunigunda、Bert 会参与地下城战斗
- **前9个标准地下城**：同伴**不参与**战斗
- **高塔及影子世界**：同伴参与辅助战斗
- 旋风地牢（Twister，130级解锁）：同伴**不参与**

### 5.4 怒气系统在地下城中的应用

- 与标准战斗相同，每回合怒气递增（1 + 回合数/6）
- 确保每场战斗必然结束，防止无限僵持

## 6. Boss 数值设计

🅱️ **B级**（社区整理）+ 🅳 **D级**（推测）

### 6.1 Boss 等级设定规律

🅱️ **B级**（玩家观测）

- 地下城 Boss 等级通常**高于解锁门槛约10~20级**
- 例：10级解锁的地下城 #1，其 Boss 等级约为 **15~20级**
- 这意味着刚解锁时未必能通关，需积累装备后再挑战

### 6.2 Boss 数值构成

🅳 **D级**（推测，基于游戏规律）

Boss 使用与玩家相同的战斗计算公式：

| 数值组件 | Boss 特点 |
|---------|---------|
| HP | 通常比同等级玩家高 50%~200% |
| 主属性 | 对应职业主属性（根据 Boss 外观/类型）|
| 护甲 | 根据 Boss 类型（战士型/远程型）有差异 |
| 暴击 | 有幸运属性，会触发暴击 |

### 6.3 Boss 职业类型（地下城 #1~#3 推测）

🅳 **D级**（推测）

| 地下城 | Boss 类型 | 特点推测 |
|--------|---------|---------|
| #1 亵渎的地下墓穴 | 不死生物/骷髅类 | 中等血量，近战攻击 |
| #2 格洛莉亚矿坑 | 矿工/地精类 | 较高护甲，中等伤害 |
| #3 纳克遗迹 | 古代巨人/遗迹守护者 | 高血量，高护甲 |

| #3（Lv30）| 史诗概率明显提升 |

- 地下城 #3 Boss：约 **15~25%** 史诗概率
- 具体概率无官方文档

🅳 **D级**（基于战斗系统推测）

## 9. 高塔（Tower）系统

🅰️ **A级**（官方帮助中心）

### 9.1 解锁条件

- **前提**：完全通关地下城 #1~#9（全部9个标准地下城）
- **触发**：通关第9个地下城后，高塔（Tower）在地图上解锁

### 9.2 高塔机制

| 参数 | 说明 |
|------|------|
| **层数** | 无限层（Infinite） |
| **难度** | 层数越高，敌人越强 |
| **通关意义** | 到达特定层数解锁**影子世界（Shadow World）** |
| **重置规则** | 不重置（永久保留最高通关层数）|
| **同伴参与** | 是（Mark/Kunigunda/Bert 参与辅助）|

### 9.3 高塔的战略意义

🅱️ **B级**（社区攻略）

- 高塔是游戏**中期最重要的里程碑目标**
- 通关高塔后解锁的**影子世界（Shadow World）**是高端装备的主要来源
- 每层高塔奖励与层数成正比，长期刷塔是稳定强化路线

## 11. 数值设计分析

🅳 **D级**（推测）

### 11.1 地下城难度曲线与玩家成长的关系

地下城设计存在**刻意的"等级差距"**：
- 解锁等级 ≠ 建议通关等级（差距约5~10级）
- 这制造了**"解锁了但打不过"**的状态，驱动玩家继续成长

```
地下城挑战感知曲线：
解锁 → 尝试失败（挫折 = 成长动力）→ 积累装备/等级 → 通关（成就感）→ 寻找下一个地下城
```

### 11.2 奖励频率设计

| 类型 | 频率 | 说明 |
|------|------|------|
| 任务奖励 | 每5~20分钟 | 高频，小额 |
| 地下城奖励 | 每日1次 | 低频，大额（史诗装备）|
| 竞技场奖励 | 每日约10次 | 中频，荣誉积累 |

地下城通过**低频次、高质量奖励**维持玩家的每日登录动力。

### 12.2 地下城运行器（核心逻辑）

```javascript

    this.player = player;
    this.dungeon = DUNGEONS[dungeonId];
    this.currentEnemyIndex = player.dungeonProgress[dungeonId] || 0;
    this.results = [];
  }
  
  // 进行一场战斗
  fightNextEnemy() {
    if (this.currentEnemyIndex >= this.dungeon.enemies.length) {
      return { status: 'completed', message: '地下城已通关' };
    }
    
    const enemy = this.dungeon.enemies[this.currentEnemyIndex];
    const battle = new BattleSimulator(this.player, enemy);
    const result = battle.run();
    
    if (result === 'attacker_wins') {
      this.currentEnemyIndex++;
      this.results.push({ enemy, result: 'win' });
      
      // Boss通关奖励
      if (enemy.isBoss) {
        return { status: 'boss_defeated', reward: this.rollBossReward() };
      }
      return { status: 'continue', nextEnemy: this.dungeon.enemies[this.currentEnemyIndex] };
    } else {
      // 失败：保存进度（不重置）
      this.saveProgress();
      return { status: 'failed', enemy, canRetryTomorrow: true };
    }
  }
  
  rollBossReward() {
    const { epicChance, legendaryChance = 0 } = this.dungeon.rewards.boss;
    const roll = Math.random();
    let quality = 'normal';
    if (roll < legendaryChance) quality = 'legendary';
    else if (roll < epicChance) quality = 'epic';
    
    return generateEquipment(this.player.level, randomSlot(), quality);
  }
  
  // 保存通关进度（失败时保留当前进度）
  saveProgress() {
    this.player.dungeonProgress[this.dungeon.id] = this.currentEnemyIndex;
  }
}
```

### 12.3 钥匙系统

```javascript
class KeySystem {
  constructor(player) {
    this.player = player;
    this.keys = player.dungeonKeys || {};  // { 1: 2, 2: 1, 3: 0 }
    this.MAX_KEYS = { 1: 3, 2: 3, 3: 3 }; // 每种最多持有3把
  }
  
  // 任务掉落时尝试获得钥匙
  tryDropKey(questDuration) {
    // 掉落概率随任务时长略有差异
    const dropChance = 0.03; // 约3%
    const dungeonLevel = this.determineDroppableKey();
    if (dungeonLevel && Math.random() < dropChance) {
      this.addKey(dungeonLevel);
    }
  }
  
  // 确定当前可掉落的钥匙类型（基于角色等级）
  determineDroppableKey() {
    const level = this.player.level;
    if (level >= 30 && this.keys[3] < this.MAX_KEYS[3]) return 3;
    if (level >= 20 && this.keys[2] < this.MAX_KEYS[2]) return 2;
    if (level >= 10 && this.keys[1] < this.MAX_KEYS[1]) return 1;
    return null;
  }
  
  addKey(dungeonId) {
    this.keys[dungeonId] = Math.min(
      (this.keys[dungeonId] || 0) + 1,
      this.MAX_KEYS[dungeonId]
    );
  }
  
  useKey(dungeonId) {
    if ((this.keys[dungeonId] || 0) > 0) {
      this.keys[dungeonId]--;
      return true;
    }
    return false; // 无钥匙
  }
}
```
