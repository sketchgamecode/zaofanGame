## 1. 系统概述与设计目标

🅰️ **A级**（官方帮助中心）

### 1.1 系统定位

任务系统是 SF Game 的**核心 Idle 循环**。它是游戏中几乎所有资源（经验/金币/装备/道具）的**主要来源**，其设计决定了玩家的"主动操作频率"和游戏节奏。

**核心设计哲学**：
- 玩家**每隔固定时间返回**游戏，选择下一个任务，收取奖励
- 操作极其简单（每次只需3选1），但存在**效率优化空间**（高亮任务、最佳时长选择）
- 用"口渴值"作为每日上限资源，平衡付费玩家和免费玩家差距

### 1.2 任务系统在游戏循环中的位置

```
[任务倒计时结束]
     ↓
[玩家进入酒馆]
     ↓
[收取奖励：EXP + 金币 + 随机掉落]
     ↓
[展示3个新任务选项]
     ↓
[玩家选择（3选1）]
     ↓
[新任务开始倒计时]
     ↓
（循环）
```

## 2. 任务选择界面

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 2.1 任务槽位规格

| 参数 | 数值 | 备注 |
|------|------|------|
| 同时展示任务数 | **3 个** | 固定，不可扩充 |
| 同时执行任务数 | **1 个** | 执行中只能有一个 |
| 任务解锁等级 | **1 级** | 游戏起点即可用 |
| 任务完成后展示方式 | 完成后**全部3个刷新** | 非仅刷新已完成的那1个 |

### 2.2 任务信息展示

每个任务选项显示以下信息：
- 任务名称（纯装饰性文本，无功能意义）
- 任务时长（分钟）
- 经验奖励预览（EXP值）
- 金币奖励预览（Gold值）
- 特殊奖励图标（如有：装备图标/蘑菇/堡垒资源等）

## 3. 任务时长机制

### 3.1 早期任务时长（1~15级）

🅰️ **A级**（sfporadnik.pl）

1~15 级时任务时长为**较短的固定小数值**，具体档位与等级相关：

| 等级段 | 典型任务时长范围 |
|--------|---------------|
| 1~5 级 | 约 1~5 分钟 |
| 5~10 级 | 约 2~8 分钟 |
| 10~15 级 | 约 3~12 分钟 |

> 这一阶段任务频率高，让新玩家快速体验核心循环并积累早期经验。

### 3.2 标准任务时长（16级起）

🅰️ **A级**（sfporadnik.pl，明确记录）

从 **16 级**起，任务时长切换为**4个标准档位**：

| 档位 | 时长 | 口渴值消耗 | 设计用途 |
|------|------|----------|---------|
| **短任务** | 5 分钟 | 5 点 | 快速回转，经验/时间效率最高（每分钟EXP最高） |
| **中短任务** | 10 分钟 | 10 点 | 主力任务，适中效率 |
| **中长任务** | 15 分钟 | 15 点 | 总奖励量较高，但效率偏低 |
| **长任务** | 20 分钟 | 20 点 | 总奖励最高，效率最低 |

> 🗒️ **重要**：3个同时展示的任务中，通常3个档位各不相同（偶有重复），给玩家选择空间。任务时长的存在使"等待时间"本身成为一种策略变量。

### 3.3 时长与口渴值消耗的关系

🅰️ **A级**（sfporadnik.pl）

每分钟任务消耗 **1 点**口渴值。即：
- 5分钟任务 = 消耗5点口渴值
- 20分钟任务 = 消耗20点口渴值

口渴值总量决定每日可执行的总任务时长上限（详见第4节）。

## 4. 冒险口渴值系统（任务燃料）

### 4.1 系统定义

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

口渴值（Thirst for Adventure）是玩家每日可进行任务的**燃料上限**。每执行1分钟任务消耗1点口渴值；口渴值耗尽后，无法开始新任务（但当前进行中的任务不受影响）。

### 4.2 口渴值参数表

| 参数 | 数值 | 来源 |
|------|------|------|
| **基础每日口渴值** | **100 点** | 🅰️ 官方 |
| 每分钟任务消耗 | 1 点 | 🅰️ 官方 |
| 基础100点可执行时长 | 100 分钟/天 | 推算 |
| **啤酒（Beer）每次恢复** | **20 点** | 🅰️ 官方 |
| **每日啤酒上限** | **10 杯**（+200点） | 🅰️ 官方 |
| 啤酒来源 | 酒馆免费提供（每日10杯） | 🅰️ 官方 |
| 喝完10杯后总口渴值 | **300 点**（100+200） | 推算 |
| **女巫附魔口渴值上限加成** | **+20 点**（基础上限变120） | 🅰️ 官方 |
| **蘑菇扩充上限** | 可达约 **320 点/天** | 🅱️ B级 |

### 4.3 口渴值恢复机制

🅰️ **A级**（官方帮助中心）

- **每日凌晨重置**：口渴值在每日服务器重置时（通常午夜或特定时间）重新满，清零当日已消耗部分
- **啤酒即时恢复**：在酒馆点击喝酒，立即+20点，一天最多喝10杯
- **冒险计时器（Adventuromatic）**：堡垒建筑，最高15级，可以**储存**未使用的口渴值，供后续使用（详见堡垒系统）

### 4.4 口渴值上限的意义

🅳 **D级**（策划分析）

口渴值系统是"软付费引导"的核心设计：
- **免费玩家**：每天约300点口渴值（10杯啤酒），可执行约300分钟任务（约15次×20分钟任务）
- **付费玩家**：通过蘑菇购买额外口渴值，可执行更多任务，加速成长
- 该机制使免费玩家每日收益受限，同时保证基础体验不受影响

## 5. 经验奖励公式

### 5.1 核心公式

🅱️ **B级**（sfporadnik.pl 玩家总结 + 社区数据验证）

任务经验奖励与以下因素成正比：

```
任务经验 ≈ 角色等级 × 任务时长(分钟) × K

K（任务品质系数）：
  - 普通任务：K ≈ 18~22（每等级每分钟经验）
  - 高亮任务：K ≈ 24~40（奖励提升约30%~100%）
```

### 5.2 经验奖励样本数据

🅱️ **B级**（社区玩家实测记录整理）

| 角色等级 | 5分钟任务经验 | 10分钟任务经验 | 20分钟任务经验 | 每分钟每级产出 |
|---------|------------|-------------|-------------|------------|
| 10 | ~90~110 | ~180~220 | ~370~440 | ~18~22 |
| 20 | ~180~220 | ~360~440 | ~720~880 | ~18~22 |
| 30 | ~270~330 | ~540~660 | ~1080~1320 | ~18~22 |
| 50 | ~450~550 | ~900~1100 | ~1800~2200 | ~18~22 |
| 100 | ~900~1100 | ~1800~2200 | ~3600~4400 | ~18~22 |

> 📊 **结论**：每分钟每等级产出约 **18~22 经验点**（普通任务区间），数值随等级**线性增长**。

### 5.3 经验公式的关键规律

| 规律 | 说明 |
|------|------|
| **与等级线性正比** | 20级角色的任务经验约为10级角色的2倍（同等时长） |
| **与时长线性正比** | 20分钟任务经验 ≈ 5分钟任务经验 × 4（稍有偏差） |
| **短任务效率更高** | 5分钟任务的"每分钟经验"通常高于20分钟任务（游戏设计倾向于鼓励短任务） |

## 6. 金币奖励公式

### 6.1 核心公式

🅱️ **B级**（sfporadnik.pl + 社区数据）

```
任务金币 ≈ 角色等级 × 任务时长(分钟) × G

G（金币系数）：
  - 普通任务：G ≈ 3.0~5.0
  - 高亮任务：G 提升约 30%~100%
```

### 6.2 金币奖励样本

🅱️ **B级**（玩家实测估算）

| 角色等级 | 5分钟任务金币 | 20分钟任务金币 | 每分钟每级产出 |
|---------|------------|-------------|------------|
| 10 | ~150~250 | ~600~1000 | ~30~50 |
| 20 | ~300~500 | ~1200~2000 | ~30~50 |
| 50 | ~750~1250 | ~3000~5000 | ~30~50 |

### 6.3 金币与经验的比例关系

🅱️ **B级**

- 单位时间内，金币数量 ≈ 经验数量 × **约3~4倍**（数值上）
- 金币的主要消耗：装备购买、属性点升级

## 7. 额外奖励（物品/道具掉落）

### 7.1 额外奖励类型

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

任务完成除了固定的经验/金币外，还有一定概率掉落**额外奖励**：

| 奖励类型 | 解锁等级 | 掉落概率 | 说明 |
|---------|---------|---------|------|
| **装备（Equipment）** | 1级 | 常见 | 与当前角色等级匹配的装备 |
| **蘑菇（Mushroom）** | 1级 | 低概率 | 高级货币，有时数量极少（1~3个） |
| **地下城钥匙** | 10级+ | 中等概率 | 各地下城专属钥匙，按地下城解锁等级 |
| **堡垒资源（石材/木材）** | 25级+ | 低概率 | 堡垒建设资源 |
| **宠物蛋** | 75级+ | 低概率 | 宠物系统素材 |
| **魔法镜碎片** | 50级+ | 极低概率 | 收集13片解锁魔法镜 |
| **啤酒** | 1级 | 常见 | 恢复口渴值20点 |
| **书本（EXP加成道具）** | 15级+ | 低概率 | 提供经验加成 |

### 7.2 掉落规则

🅱️ **B级**（社区总结）

- **最多1件额外奖励**：每次任务最多掉落1件额外道具（不会同时掉落多件）
- **掉落无保底**：纯随机，连续多次任务也可能不掉落
- **等级越高掉落质量越好**：例如装备与当前等级匹配，地下城钥匙与已解锁的地下城对应

## 8. 高亮任务机制

### 8.1 机制描述

🅰️ **A级**（sfporadnik.pl + 官方帮助中心）

在3个任务选项中，偶尔出现**高亮标注的任务**（通常显示为红色、金色或有特殊图标）：

| 参数 | 说明 |
|------|------|
| 出现概率 | 约 10%~20%（非官方精确数值，🅱️ B级） |
| 奖励提升 | 经验 + 金币均有约 **30%~100% 的额外加成** |
| 外观特征 | 任务名称/背景以红色/金色高亮显示 |
| 是否影响时长 | **不影响**，时长与普通任务相同 |
| 额外掉落 | 高亮任务额外掉落概率也更高（🅱️ B级）|

### 8.2 高亮任务的策略价值

🅱️ **B级**（社区共识）

- **优先选择高亮任务**是普遍共识的最优策略
- 高亮任务的"效率加成"使短高亮任务（5分钟）效率远超长普通任务（20分钟）
- 玩家可利用**任务刷新机制**来等待高亮任务出现（蘑菇刷新或等待自动刷新）

## 9. 坐骑对任务的加速效果

### 9.1 坐骑系统概述

🅰️ **A级**（官方帮助中心）

在**马厩（Stable）**（5级解锁）可以租赁坐骑，坐骑会**直接缩短任务完成时间**：

| 坐骑类型 | 费用 | 有效期 | 任务时间缩短比例 |
|---------|------|-------|--------------|
| 基础坐骑（马） | 低 | 短 | 约 10% |
| 中级坐骑（骏马） | 中 | 中 | 约 20% |
| **狮鹫（Griffin）** | 25蘑菇 | **14天** | **50%**（任务次数约翻倍） |
| 顶级坐骑 | 高蘑菇 | 长 | 更高 |

> 🗒️ **注意**：坐骑缩短时间意味着口渴值消耗速度不变，但同等口渴值完成的任务次数增加。

### 9.2 坐骑对效率的影响（以狮鹫为例）

🅱️ **B级**（社区分析）

无坐骑时，5分钟任务实际耗时5分钟；有50%缩短效果的坐骑时，实际耗时 2.5分钟。
这意味着口渴值相同时，**每天可执行约2倍数量的任务**，经验/金币总收益约翻倍。

## 10. 书本道具（经验加成）

### 10.1 书本类型

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

| 书本类型 | 加成比例 | 解锁/来源 | 有效期 |
|---------|---------|---------|-------|
| **小书（+10% EXP）** | +10% 经验 | 魔法商店购买 | 持续到下次登录 |
| **中书（+25% EXP）** | +25% 经验 | 15级起可购买 | 同上 |
| **大书（+50% EXP）** | +50% 经验 | 高等级解锁 | 同上 |

> 🗒️ 书本是任务经验的**倍率加成**，作用于基础任务经验+高亮任务加成之后的最终值。

### 10.2 书本叠加规则

🅱️ **B级**（社区讨论）

- 同时只能有一本书的加成生效
- 更换新书时旧书失效
- 书本加成对所有经验来源生效（任务经验、战斗经验等）

## 11. 任务效率最优化策略

### 11.1 效率评估公式

🅱️ **B级**（社区玩家总结）

```
经验效率 = 预期EXP ÷ 任务时间（分钟）
金币效率 = 预期金币 ÷ 任务时间（分钟）
口渴效率 = 预期EXP ÷ 口渴值消耗（等同于EXP/时间）
```

### 11.2 最优选择逻辑

🅱️ **B级**（社区共识）

```
优先级：
1. 高亮任务 > 普通任务（无论时长）
2. 同为普通任务：选经验效率最高者
3. 经验效率相同时：选时间较短者（更快回转）
4. 金币紧张时：选金币效率高的任务
```

### 11.3 不同阶段的策略侧重

| 游戏阶段 | 首要目标 | 推荐策略 |
|---------|---------|---------|
| 1~15级 | 快速升级 | 优先选最短时长任务，回转快 |
| 16~25级 | 升级+解锁堡垒 | 选经验效率高的任务（优先高亮） |
| 25~30级 | 升级+积累金币 | 平衡经验效率和金币效率 |

## 13. 复刻实现要点

### 13.1 核心数据结构

```javascript
// 任务对象
Task {
  id: String,           // 任务唯一ID
  duration: Number,     // 时长（分钟）：5/10/15/20
  exp: Number,          // 经验奖励
  gold: Number,         // 金币奖励
  isHighlighted: Bool,  // 是否高亮任务
  bonusItem: Item|null  // 额外奖励（可为空）
}

// 玩家任务状态
PlayerQuestState {
  activeTask: Task|null,      // 当前进行中的任务
  taskEndTime: Timestamp,     // 任务结束时间戳
  dailyThirst: Number,        // 今日剩余口渴值
  maxThirst: Number,          // 口渴值上限（基础100，可扩展）
  availableTasks: Task[3],    // 当前展示的3个任务
  beersLeft: Number           // 今日剩余啤酒杯数（上限10）
}
```

### 13.2 经验公式实现参考

```javascript
// 任务经验计算
function calculateQuestExp(playerLevel, durationMin, isHighlighted) {
  const K_base = 20; // 每等级每分钟经验基准值（可调参）
  const highlight_multiplier = isHighlighted ? 1.5 : 1.0; // 高亮加成（1.3~2.0区间可调）
  const bookMultiplier = getBookBonus(); // 书本加成（1.0/1.1/1.25/1.5）
  
  return Math.floor(playerLevel * durationMin * K_base * highlight_multiplier * bookMultiplier);
}

// 任务金币计算
function calculateQuestGold(playerLevel, durationMin, isHighlighted) {
  const G_base = 4.0; // 每等级每分钟金币基准值（可调参）
  const highlight_multiplier = isHighlighted ? 1.5 : 1.0;
  
  return Math.floor(playerLevel * durationMin * G_base * highlight_multiplier);
}
```

### 13.3 任务生成逻辑

```javascript
// 生成3个任务选项
function generateTasks(playerLevel) {
  const durations = [5, 10, 15, 20];
  const tasks = [];
  
  // 从4个时长中随机选3个（允许重复，但通常不同）
  const selectedDurations = shuffle(durations).slice(0, 3);
  
  for (const dur of selectedDurations) {
    const isHighlighted = Math.random() < 0.15; // 约15%高亮概率（可调参）
    tasks.push({
      duration: dur,
      exp: calculateQuestExp(playerLevel, dur, isHighlighted),
      gold: calculateQuestGold(playerLevel, dur, isHighlighted),
      isHighlighted,
      bonusItem: rollBonusItem(playerLevel)
    });
  }
  return tasks;
}
```

// 开始任务时消耗口渴值
function startQuest(task) {
  if (player.dailyThirst < task.duration) {
    return { success: false, reason: "口渴值不足" };
  }
  player.dailyThirst -= task.duration;
  player.activeTask = task;
  player.taskEndTime = Date.now() + task.duration * 60 * 1000;
  return { success: true };
}

// 喝啤酒恢复口渴值
function drinkBeer() {
  if (player.beersLeft <= 0) return false;
  player.dailyThirst = Math.min(player.maxThirst, player.dailyThirst + 20);
  player.beersLeft -= 1;
  return true;
}
