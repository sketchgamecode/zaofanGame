## 1. 游戏概述

🅰️ **A级**（官方帮助中心）

- **类型**：浏览器/手机 闲置 RPG（Idle RPG）
- **开发商**：Playa Games GmbH（德国）
- **核心循环**：派遣角色执行任务（自动倒计时）→ 收取经验/金币 → 升级/强化装备 → 挑战地下城/竞技场
- **时间驱动**：几乎所有行为（任务、建造、战斗）均为定时器驱动，玩家不直接操控战斗过程
- **消耗品**：蘑菇（高级货币）、冒险口渴值（任务燃料）

#### 职业详细特性补充

🅰️ **A级**（Playa Games 官方）

**战斗法师 Battle Mage**
- 护甲系数 500%（可达极高护甲值）
- 奥术彗星：始终被法师和战斗法师自身格挡；伤害取敌方生命值 33% 上限

**德鲁伊 Druid**
- 鹰形态：基础15%触发率（每次+5%，上限50%）
- 熊形态：闪避时触发，持续1回合；暴击上限75%；不能俯冲
- 无法对法师使用闪避，但对法师造成额外33%伤害
- 对恶魔猎手造成额外15%伤害

**吟游诗人 Bard**
- 旋律等级1（25%触发率）：武器伤害+20%
- 旋律等级2（50%触发率）：武器伤害+40%
- 旋律等级3（25%触发率）：武器伤害+60%

**死灵法师 Necromancer**
- 骷髅：召唤3回合，50%几率复活（最多2次），伤害+25%
- 恶犬：召唤2回合，伤害+100%，暴击+10%（上限60%），暴击伤害+50%
- 魔像：召唤4回合，25%几率格挡攻击
- 对恶魔猎手造成+10%伤害

**圣骑士 Paladin**
- 防御姿态：50%格挡伤害并回复格挡伤害的30%生命，50%几率切为进攻姿态，武器系数0.568
- 进攻姿态：50%几率切回普通，武器系数1.253，最大护甲降至20%，格挡率25%
- 对法师不切换姿态

## 4. 战斗系统（核心公式）

> **来源说明**：以下公式逆向自 sf-tools 开源战斗模拟器（GitHub: HafisCZ/sf-tools，js/sim/base.js），该工具由社区开发者长期与真实游戏数据对照验证，精度极高，但属于非官方来源。

### 4.1 生命值（HP）计算

🅲 **C级**（sf-tools 源码逆向）

```
HP = 体力(Constitution.Total)
   × 职业生命倍率
   × (1 + 零食体力加成)
   × (等级 + 1)
   × (1 + 生命药水加成/100)
   × (1 + 个人副本生命加成/100)
   × (1 + 生命符文加成/100)
   × 自定义生命倍率
```

全部乘积结果向上取整（Math.ceil）。

**各职业生命倍率**：

| 职业 | 倍率 |
|------|------|
| 圣骑士 | ×6 |
| 战士 / 战斗法师 / 德鲁伊 | ×5 |
| 游侠 / 刺客 / 恶魔猎手 / 死灵法师 / 狂战士 | ×4 |
| 法师 / 吟游诗人 | ×2 |

---

### 4.2 护甲减伤

🅲 **C级**（sf-tools 源码）

```
减伤% = 职业减伤上限修正因子
       × min(基础最大减伤 + 零食最大减伤加成, 护甲值 / 攻击方等级)
```

**各职业护甲上限**：

| 职业 | 最大减伤 |
|------|---------|
| 战士 / 恶魔猎手 / 战斗法师 / 狂战士 | 50% |
| 圣骑士 | 45%（进攻姿态时降至 20%） |
| 游侠 / 刺客 / 德鲁伊 | 25% |
| 法师 / 吟游诗人 | 10% |
| 死灵法师 | 10% |

**特殊规则**：
- 法师攻击：**绕过目标全部护甲减伤**（BypassDamageReduction）
- 德鲁伊熊形态：减伤提升至 50%

---

### 4.3 伤害计算

🅲 **C级**（sf-tools 源码）

```
基础伤害系数 =
    (1 + 队伍副本伤害加成/100)
  × (1 - 目标护甲减伤%)
  × [1 + (1 - min(75, 敌方抗性)/100) × min(60, 己方伤害符文)/100]  ← 符文系统
  × 职业伤害系数
  × [1 + max(主属性/2, 主属性 - 目标主属性/2) / 10]  ← 属性差对比
  × (1 + 零食伤害加成/100)
```

```
实际伤害 = 基础伤害系数 × 武器伤害值（随机在 Min~Max 之间）
```

**属性差公式说明**：
- 当自身主属性 > 目标主属性时，差值越大，伤害加成越高
- 属性差计算：`max(主属性/2, 主属性 - 对方主属性/2)` / 10

---

### 4.4 暴击系统

🅲 **C级**（sf-tools 源码）

**暴击率**：
```
暴击率 = min(50%, 暴击基础值 + 幸运 × 2.5 / 目标等级 / 100)
```

**暴击倍率**：
```
暴击伤害倍率 = 2.0（基础）
            + 0.05（武器附魔加成）
            + 0.11 × (自身竞技场等级 - 目标竞技场等级)  ← 竞技场加成
            + 零食暴击倍率加成
```

---

### 4.5 怒气系统（每回合递增）

🅲 **C级**（sf-tools 源码）

```
怒气倍率 = 1 + 当前回合数 / 6
```

| 回合 | 怒气倍率 |
|------|---------|
| 1 | 1.00 |
| 6 | 2.00 |
| 12 | 3.00 |
| 18 | 4.00 |

> **作用**：怒气值乘入最终伤害，防止战斗无限僵持。

---

### 4.6 战斗流程（回合制）

🅱️ **B级**（攻略站归纳 + C级源码验证）

1. 战斗开始前：触发开场技能（如战斗法师奥术彗星、圣骑士姿态、吟游诗人旋律等）
2. 每回合：攻击方发出攻击
3. 防御方判定：
   - **格挡**（战士/圣骑士）：概率格挡，取消本次伤害
   - **闪避**（游侠/刺客/德鲁伊）：概率闪避，取消本次伤害
   - 若未格挡/闪避，则进入伤害计算
4. 伤害计算：主属性差 → 护甲减伤 → 暴击判定 → 怒气加成 → 最终 HP 扣减
5. 检测 HP：任一方 HP ≤ 0，战斗结束
6. 特殊触发：恶魔猎手复活、德鲁伊形态切换、狂战士连击等
7. **战斗上限**：若超过特定回合数仍未分出胜负，怒气系统会强制放大伤害直至结束

## 5. 等级与成长曲线

### 5.1 升级所需经验值（关键节点）

🅰️ **A级**（sfporadnik.pl 完整数据表）

| 等级 | 所需 EXP（累积） |
|------|----------------|
| 1→2 | 400 |
| 5→6 | 2,200 |
| 10→11 | 6,435 |
| 20→21 | 28,660 |
| 50→51 | 320,685 |
| 100→101 | 3,391,480 |
| 200→201 | 58,348,500 |
| 300→301 | 389,630,630 |
| 350→351 | 828,158,780 |

> 📈 **规律**：经验需求呈**超指数增长**，早期较平缓，100级后急剧攀升。实际上游玩的"主流玩家区间"集中在50~350级。

### 5.2 等级对数值的影响

🅰️ **A级** + 🅲 **C级**

- **HP 直接乘以 (等级+1)**：等级每涨1级，HP 同比线性增长
- **护甲减伤 = 护甲/敌方等级**：高等级对低等级护甲减伤更高
- **暴击率受目标等级压制**：幸运 × 2.5 / 目标等级，等级差大时幸运收益下降

## 6. 任务系统

🅰️ **A级**（sfporadnik.pl + Playa Games 官方帮助中心）

### 6.1 核心机制

- 每次同时展示 **3个任务**选项，各自有不同时间/金币/经验奖励
- 等级16之前：任务时间为固定档位
- 等级16之后：任务时长 5 / 10 / 15 / 20 分钟（标准档位）
- 偶尔出现**红色高亮任务**（奖励更丰厚，优先选择）
- 额外奖励：装备、蘑菇、堡垒资源、地下城钥匙、宠物蛋等

### 6.2 冒险口渴值系统

| 参数 | 数值 |
|------|------|
| 基础每日口渴值 | 100点 |
| 每分钟任务消耗 | 1点 |
| 啤酒每次恢复 | 20点 |
| 每日啤酒上限 | 10杯（+200点） |
| 女巫附魔口渴值加成 | +20点（上限120点/天基础） |
| 蘑菇扩充 | 可达320点/天 |

### 6.3 最优任务选择策略

🅱️ **B级**（玩家社区经验）

```
经验效率 = 经验值 ÷ 任务时间（分钟）
金币效率 = 金币 ÷ 任务时间（分钟）
```
- 优先选 **经验效率最高**的任务（主要目标是升级）
- 同效率时选时间较短（回转更快，更灵活）

### 6.4 坐骑对任务的影响

🅰️ **A级**（官方帮助中心）

- 坐骑可缩短任务时间（具体比例见马厩系统）
- **狮鹫坐骑**（25蘑菇，14天）：14天内任务总次数翻倍（最具性价比）

## 7. 装备系统

### 7.1 装备品质

🅰️ **A级**（官方帮助中心 + B级社区）

| 品质 | 颜色/标识 | 特性 |
|------|----------|------|
| **普通 Normal** | 白 | 基础属性，无特殊 |
| **史诗 Epic** | 橙/金 | 50级后商店出现，属性更高，可能含宝石槽/符文 |
| **传奇 Legendary** | 紫/彩 | 最高品质，自带1个宝石槽 + 1个符文 |

- 装备属性与角色当前等级挂钩，同一件装备在不同等级下找到会有不同强度
- 每种装备有对应职业限制（武器类型与职业绑定）

### 7.2 铁匠（Blacksmith）服务

🅰️ **A级**（官方帮助中心）

解锁等级：90级

| 服务 | 说明 |
|------|------|
| **宝石槽升级** | 为装备添加宝石镶嵌槽（消耗金属+奥术碎片） |
| **属性升级** | 单件装备最多强化 20 次，每次提升属性值 |
| **宝石提取** | 移除宝石并返还 |
| **符文替换** | 交换两件装备的符文属性 |
| **外观修改** | 史诗/传奇装备可花费 10蘑菇 修改外观 |
| **物品拆解** | 每日最多 5件，获得金属+奥术碎片 |

### 7.3 宝石系统

🅱️ **B级**（攻略站 number13.de）

宝石强度取决于：
1. **角色等级**
2. **宝石大小**（小/中/大）
3. **堡垒宝石矿等级**（最高100级）
4. **公会骑士大厅等级总和**

- 传奇宝石：图书馆中存在至少1件传奇装备图片后，宝石矿才可能开采出
- 宝石镶嵌到装备槽位中，提供各类属性加成（力量、智力、幸运等）

### 7.4 符文系统

🅲 **C级**（sf-tools 源码逆向 + B级社区）

- 符文提供**伤害符文**或**抗性符文**
- 伤害符文上限：60点（影响伤害计算）
- 抗性符文上限：75点（影响受到伤害）
- 竞技场经理等级差影响暴击倍率（每级差 × 0.11）

### 7.5 女巫（Witch）附魔

🅰️ **A级**（官方帮助中心）

- 解锁等级：66级
- 可对装备附加各类魔法效果（如增加口渴值上限、提升特定属性等）
- 附魔的装备不能被同伴穿戴后生效（规则：同伴穿附魔装备时附魔失效）
