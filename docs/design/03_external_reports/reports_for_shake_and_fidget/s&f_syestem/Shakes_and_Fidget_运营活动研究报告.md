## 1. 游戏付费体系概览

### 核心付费货币: 蘑菇 (Mushroom)

蘑菇是 S&F 的唯一高级货币，几乎所有付费行为都通过蘑菇完成。

| 获取方式 | 说明 |
|----------|------|
| 免费获取 | 每日首个任务保证掉落; 100/300体力冒险后奖励; 每日登录日历; 兑换码; 赌徒小游戏 |
| 付费购买 | 蘑菇经销商 (支持 PayPal/手机/短信/iTunes/Google Pay) |
| 活动加成 | 特定活动期间蘑菇掉率提升 / 购买赠送额外蘑菇 |

### 蘑菇主要消耗用途

| 用途 | 消耗量 | 说明 |
|------|--------|------|
| 购买坐骑 | 25-300+ | 加速任务完成时间 |
| 跳过任务 | 1蘑菇/次 | 刷新不想要的任务 |
| 购买啤酒 | 1蘑菇 | 加速任务 |
| 地牢钥匙 | 1蘑菇 | 缺少钥匙时替代 |
| Hellevator钥匙卡 | 1蘑菇 | 缺少钥匙卡时替代 |
| 马戏团票 | 1蘑菇 | 缺少普通票时替代 |
| Beelzebub增益 | 蘑菇 | 缺少钥匙卡时替代购买 |
| Black Market | 蘑菇/Lucky Coins | 购买轮换道具 |
| 世界Boss弹射器升级 | 蘑菇+催化剂+资源 | 增加伤害 |

### 一次性蘑菇礼包 (按等级解锁)

| 礼包名称 | 等级要求 | 内容 |
|----------|----------|------|
| Starter Pack | 1-20 | 150蘑菇 + 1000金 + 永生药水 + 4周最佳坐骑 |
| Fortress Pack | ≤100 | 300蘑菇 + 10万木 + 5万石 + 1级经验 |
| Pro Pack | 120+ | 750蘑菇 + 1000沙漏 + 10万灵魂 + 5万奥术碎片 |
| Pro+ Pack | 150+ | 1500蘑菇 + 1500沙漏 + 15万灵魂 + 7.5万奥术碎片 |
| Pro Pro Pack | 200+ | 3250蘑菇 + 2500沙漏 + 20万灵魂 + 10万奥术碎片 |
| Pro++ Pack | 250+ | 1500蘑菇 + 1500沙漏 + 10万奥术碎片 + 500幸运币 |
| Triple Pro Pack | 300+ | 3350蘑菇 + 2500沙漏 + 15万奥术碎片 + 1000幸运币 |

> **来源可信度**: 官方帮助中心 (playa-games.helpshift.com)

## 2. 节日限时活动

### 2.1 复活节 - 蛋猎活动 (Egg Hunt)

| 项目 | 详情 |
|------|------|
| **时间** | 复活节期间，通常周五至周一 (4天) |
| **前提条件** | 必须解锁宠物系统 |
| **核心机制** | Goblin Gleeman 发布限时任务，完成任务获得活动积分 |
| **积分奖励** | 2分 → 5种水果各5个 (或普通宠物); 4分 → 水果篮 + 额外啤酒; 5分+ → 稀有宠物 |
| **重要说明** | 超过5分也可收集，不必完成所有任务; 已解锁全部宠物则获得水果篮替代 |
| **付费关联** | 无直接付费，但拥有坐骑加速可更快完成任务 |

> **来源可信度**: 官方帮助中心

### 2.2 万圣节 - 黑宝石潮 (Black Gem Rush)

| 项目 | 详情 |
|------|------|
| **时间** | 万圣节期间，通常周四至周日 |
| **核心机制** | 宝石矿中只产出黑宝石; 传奇宝石掉率不变 |
| **意义** | 黑宝石是最高等级宝石，平时产出概率极低 |
| **付费关联** | 常与 Epic Shopping Spree 等增益活动同期举办; 2021年 Black Friday 与蘑菇促销同开 |

> **来源可信度**: 官方帮助中心 + Steam新闻 + sfporadnik.pl

### 2.3 圣诞节 - 全活动同开

| 项目 | 详情 |
|------|------|
| **时间** | 12月23-26日 (4天) |
| **核心机制** | "就像圣诞节和复活节同时到来" — 所有增益活动同时开启 |
| **包含活动** | 更多XP + 更多金币 + 更多史诗(Lv50+) + 更多蘑菇 + 森林稀有物 + 蘑菇促销(+20%额外蘑菇) |
| **付费关联** | **强付费配合** — 蘑菇促销 +20% 是核心吸引力 |

> **来源可信度**: Steam官方新闻公告

### 2.4 沃尔普吉斯之夜 (Walpurgis)

| 项目 | 详情 |
|------|------|
| **时间** | 每年4月30日所在周 |
| **核心机制** | Goblin Gleeman 发布4个任务; 完成每个任务获得1积分 |
| **积分奖励** | 3分即可领取全部3个奖励 (金/额外啤酒); 不需完成全部4个任务 |
| **付费关联** | 无直接付费，任务为常规游戏行为 |

> **来源可信度**: 官方帮助中心

### 2.5 黑色星期五 (Black Friday)

| 项目 | 详情 |
|------|------|
| **时间** | 11月黑色星期五周末 |
| **蘑菇促销** | 特殊礼包 +20% 额外蘑菇; 普通蘑菇包最高 +33% 额外蘑菇 |
| **加成** | 增加任务中蘑菇掉落概率 |
| **同期活动** | Black Gem Rush + Epic Shopping Spree + Tidy Toilet Time + Assembly of Awesome Animals |
| **付费关联** | **极强付费配合** — 年度最大蘑菇折扣 + 多增益活动叠加 |

> **来源可信度**: sfporadnik.pl + Steam新闻

## 3. 赛季/周期性活动

### 3.1 夏日 Collectifun (Summer Collectifun)

| 项目 | 详情 |
|------|------|
| **时间** | 每年夏季 |
| **核心机制** | Goblin Gleeman 发布多项任务; 完成每个任务获得1积分 |
| **积分奖励** | 2分 → 金(按等级缩放); 4分 → 金 + 额外啤酒; 6分 → 传奇宝石 |
| **灵活性** | 可获得超过6分，不必完成所有任务 |
| **付费关联** | 无直接付费; 传奇宝石是极稀有奖励 |

> **来源可信度**: 官方帮助中心 + Steam新闻

### 3.2 Hellevator (地狱电梯)

| 项目 | 详情 |
|------|------|
| **类型** | 公会限定活动 |
| **核心机制** | 公会成员进入地下城，逐层击败敌人; 每日重置20层 |
| **钥匙卡系统** | 每30分钟生成1张; 上限15张; 可用1蘑菇替代 |
| **地狱攻击(公会合作)** | 5钥匙卡/天报名; 分配不同平原(每50层)同时攻击 |
| **Beelzebub增益商店** | 用钥匙卡或蘑菇购买战斗增益; 效果叠加至24层 |
| **每日奖励** | 按公会地狱代币总量发放宝箱 (要塞/铁匠/金箱) |
| **最终奖励** | 按公会排名发放; 前3名公会获得专属个人资料背景(持续至下次活动) |
| **付费关联** | **中等付费配合** — 蘑菇可替代钥匙卡战斗和购买增益 |

> **来源可信度**: 官方帮助中心 + number13.de攻略

### 3.3 世界Boss (World Boss)

| 项目 | 详情 |
|------|------|
| **核心机制** | 全服玩家共同攻击世界Boss; 弹射器系统 |
| **弹射器** | 用催化剂购买; 持续4-10小时; 自动攻击 |
| **弹药系统** | 催化剂购买; 3种弹药(普通/低血量增伤/高血量增伤) |
| **宝箱奖励** | 参与宝箱 + 击杀偷取者宝箱(5个) + 最高单次伤害宝箱(3个) + 最高总伤害宝箱(3个) |
| **排名奖励** | 铜框头像(前3-5梯队) + 幸运币 |
| **付费关联** | **强付费配合** — World Boss Pack含催化剂(替代蘑菇); 弹射器升级需蘑菇; Black Market中有活动限定礼包 |

**2026年1月更新要点**:
- World Boss Pack不再包含蘑菇，改为催化剂
- Black Market活动礼包含 Lucky Coins + 沙漏 + 蘑菇 + 材料
- 事件开始前购买可预付催化剂

> **来源可信度**: 官方Dev Blog (home.sfgame.net)

### 3.4 传奇地牢 (Legendary Dungeon)

| 项目 | 详情 |

> **来源可信度**: 官方帮助中心

### 3.5 流动马戏团 (Traveling Circus)

| 项目 | 详情 |
|------|------|

| **银色团长币** | 对团长造成伤害 | 每日排行榜 | 无 |

## 6. 活动商店与付费配合

### 6.1 蘑菇经销商 (Mushroom Dealer / WebShop)

| 商店分区 | 说明 | 付费关系 |
|----------|------|----------|
| 蘑菇包 | 标准购买，活动期间加成 | **核心付费点** |
| 一次性礼包 | Starter→Triple Pro (按等级解锁) | **深度付费点** — 引导长期留存 |
| Black Market | 7天轮换，可用幸运币或蘑菇购买 | **混合付费** — 免费幸运币 + 蘑菇购买 |
| 免费蘑菇 | 调查问卷 / 游戏下载等 | 不含+20%加成 |
| 兑换码 | 社交媒体/Twitch发放 | 免费 |

### 6.2 Beelzebub 增益商店 (Hellevator 限定)

- 使用钥匙卡或蘑菇购买战斗增益
- 增益效果叠加至24层
- 第2天起增加武器伤害加成
- **付费逻辑**: 高层需要更多增益 → 钥匙卡不够时用蘑菇 → 激励购买蘑菇

### 6.3 Kaboom 弹射器商店 (World Boss 限定)

- 催化剂购买弹射器(4-10小时)和升级
- 弹药(20/50发)用催化剂购买
- 升级需要催化剂 + 资源 + **蘑菇**
- **付费逻辑**: World Boss Pack提供催化剂; 升级需蘑菇; 最大化伤害追求排名

### 6.4 Black Market (活动期间特殊轮换)

- World Boss活动期间，Black Market推出活动限定礼包

### 促销活动频率 (2025年估计)

| 促销类型 | 年度次数 |
|----------|----------|
| Crazy Mushroom Harvest (+20%) | ~3次 |
| World Boss Sale | ~2次 |
| Silver Frame Sale | ~3次 |
| New Year's Sale | 1次 |
| Black Friday Sale (+20%/+33%) | 1次 |
| Birthday Sale | 1次 |

### 关键设计策略

1. **叠加效应**: 蘑菇促销常与多增益活动同开 (如Black Friday = 蘑菇促销 + Black Gem Rush + Epic Shopping Spree + ...)
2. **购买时机引导**: 社区共识"等Crazy Mushroom Harvest再买蘑菇"
3. **免费排除**: "Earn Mushrooms"(调查问卷)部分**不享受**+20%加成 → 区分免费/付费用户
4. **限时紧迫性**: 促销仅持续2-4天，制造FOMO

## 附录: 核心设计模式总结

### S&F 运营活动的5大设计原则

1. **活动叠加效应 (Event Stacking)**
   - 大节点(Black Friday/周年庆/圣诞)同时开启6-9个活动
   - 让玩家感觉"不玩就亏了"，最大化在线率

2. **蘑菇购买时机引导 (Purchase Timing)**
   - Crazy Mushroom Harvest (+20%) 和季节促销 (>+20%) 创造明确的"最佳购买窗口"
   - 社区共识形成"等促销再买"的习惯 → 促销期间集中付费

3. **免费参与 + 付费加速 (Free-to-Play + Pay-to-Accelerate)**
   - 所有活动均可免费参与
   - 付费(蘑菇)提供加速: 替代钥匙卡/购买增益/购买坐骑
   - 关键设计: 蘑菇替代永远有上限(15钥匙卡/15票) → 付费无法无限碾压

4. **断签惩罚 + 累积奖励 (Streak Penalty + Accumulation)**
   - 登录日历断签重置 → 习惯养成
   - 活动积分不需全部完成 → 降低挫败感
   - 第20天免费升级 → 强力锚定奖励

5. **社交竞争驱动 (Social Competition)**
   - Hellevator公会排名 → 公会内蘑菇投入压力
   - World Boss全服排名 → 伤害攀比 → 弹射器升级 → 蘑菇消耗
   - 排名专属外观 → 稀缺性炫耀 → 持续参与动力
