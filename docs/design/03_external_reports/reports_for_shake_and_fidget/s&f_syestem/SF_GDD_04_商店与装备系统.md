## 1. 系统概述与设计目标

🅰️ **A级**（官方帮助中心）

### 1.1 系统定位

装备系统是 SF Game 的**核心成长驱动器**之一：
- 装备是**外部数值来源**，与角色自身属性（内部来源）共同构成战斗数值
- 游戏的中长期目标，很大程度上就是**寻找更好的装备**
- 装备随角色等级实时缩放，保证"找到新装备 = 立即提升战力"的正反馈

### 1.2 核心设计原则

| 原则 | 具体体现 |
|------|---------|
| **随等级强制淘汰** | 装备属性值 ∝ 角色等级，旧装备自然过时 |
| **随机性驱动持续游玩** | 商店随机刷新，稀有品质驱动每日登录 |
| **多维度装备属性** | 单件装备提供主属性+护甲+武器伤害+宝石槽等，选择层次丰富 |
| **职业限制增强专属感** | 每类装备有职业限制，强化角色身份认同 |

## 2. 装备槽位与装备类型

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 2.1 装备槽位（共 10 个槽位）

| 槽位编号 | 槽位名称 | 英文 | 说明 |
|---------|---------|------|------|
| 1 | 头盔 | Head | 护甲/属性 |
| 2 | 上身盔甲 | Body | 护甲/属性，通常最重要 |
| 3 | 手套 | Gloves | 护甲/属性 |
| 4 | 鞋靴 | Boots | 护甲/属性 |
| 5 | **武器** | Weapon | 提供 MinDmg + MaxDmg |
| 6 | **护身符** | Amulet | 纯属性（无护甲）|
| 7 | **腰带** | Belt | 护甲/属性 |
| 8 | 戒指 | Ring | 纯属性 |
| 9 | 耳环 | Earrings | 纯属性 |
| 10 | **饰品/副手** | Off-Hand/Misc | 护甲 or 特殊加成 |

> 🗒️ 不同职业的副手槽位内容不同：战士/圣骑士使用盾牌（提供护甲/格挡），法系职业使用法典（提供属性），游侠使用箭袋（提供武器加成）。

| 匕首/双刃 | 刺客 |
| 弓 | 游侠 |
| 弩 | 恶魔猎手 |
| 法杖/权杖 | 法师、德鲁伊、吟游诗人、死灵法师 |

## 3. 装备品质系统

🅰️ **A级**（官方帮助中心）

### 3.1 三种装备品质

| 品质 | 颜色标识 | 解锁等级 | 特性 |
|------|---------|---------|------|
| **普通（Normal）** | 白色 | 1级 | 基础属性，无特殊 |
| **史诗（Epic）** | 橙色/金色 | 50级（商店）| 属性更高，可含宝石槽或符文 |
| **传奇（Legendary）** | 紫色/彩色 | 随机掉落 | 最高属性，自带1宝石槽 + 1符文槽 |

### 3.2 品质出现概率

🅱️ **B级**（玩家社区整理）

| 品质 | 商店基础概率 | 影响因素 |
|------|-----------|---------|
| 普通 | 约90%+ | — |
| 史诗 | 约5~10% | 50级以上才出现；奥秘之神马桶光环每升1级+1品质 |
| 传奇 | 约1~3% | 收藏册 + 至少1件传奇图册后宝石矿才能开采 |

> 🗒️ 100级以下玩家传奇极难刷到，是长期追求目标而非短期目标。

### 3.3 品质对属性的加成

🅱️ **B级**（number13.de 攻略）

史诗和传奇装备相比同等级普通装备：
- 属性值整体提升约 **20%~50%**（具体数值无官方文档，C级数据缺失）
- 传奇确保拥有宝石槽位（可额外镶嵌宝石）
- 传奇确保拥有符文槽位（伤害或抗性加成）

## 4. 装备属性生成规则

🅲 **C级**（sf-tools 装备数值逆向 + B级社区）

### 4.1 属性分配类型

每件装备根据槽位类型，可能包含以下属性：

| 属性类型 | 可能出现的槽位 | 说明 |
|---------|-------------|------|
| **主属性（力量/敏捷/智力）** | 全部槽位 | 每件装备通常有1~2个主属性 |
| **体力（Constitution）** | 全部槽位 | 影响血量 |
| **幸运（Luck）** | 全部槽位 | 影响暴击率 |
| **护甲（Armor）** | 头/身/手/靴/腰/副手 | 减少受到伤害 |
| **武器伤害（MinDmg/MaxDmg）** | 仅武器槽 | 直接影响输出 |

### 4.2 主属性优先级（不同职业）

🅳 **D级**（推测）

装备上的属性通常以职业为导向：
- 商店会根据角色职业优先展示与职业主属性匹配的装备
- 如战士（力量职业）商店更多出现力量属性装备

### 4.3 属性值与等级的关系

🅲 **C级**（sf-tools 数值反推）

```
装备属性值 ≈ f(角色等级) × 品质修正因子 × 随机波动系数
```

**关键规律**：
- 装备属性值随角色等级**线性缩放**（大致线性，局部波动）
- 等级30的装备与等级10的装备相比，属性约提升 **3倍**
- 同等级不同件数属性有约 **±15~25%** 的随机波动

> 🗒️ 由于SF Game官方未公开装备生成公式，以下为社区逆向所得，精度有限。

## 5. 商店（Shop）机制

🅰️ **A级**（官方帮助中心）

### 5.1 商店基础规则

- 商店（The Market / Magic Shops）展示**随机装备**供玩家购买
- 每个商店有**独立的刷新计时器**（通常每小时自动刷新一次）
- 玩家可花费**蘑菇（Mushrooms）即时刷新**商店
- 商店装备等级与**角色当前等级**匹配

### 5.2 商店类型

🅰️ **A级**（官方帮助中心）

| 商店名称 | 特点 | 解锁 |
|---------|------|------|
| **武器商店（Weapon Shop）** | 出售武器类装备 | 初始解锁 |
| **魔法商店（Magic Shop）** | 出售各类装备 + 特殊道具（书/宝珠）| 初始解锁 |
| **地城商店** | 特定地下城通关后解锁，出售特殊装备 | 地下城进度 |

### 5.3 商店刷新规则

🅰️ **A级**（官方帮助中心）

| 参数 | 数值 |
|------|------|
| 自动刷新频率 | 每小时一次（或更长，具体待确认）|
| 手动刷新费用 | 1 蘑菇（Mushroom）|
| 每日最大手动刷新次数 | 不限（消耗蘑菇）|
| 装备等级 | = 角色当前等级（动态匹配）|

### 5.4 商店购买价格

🅱️ **B级**（社区整理）

```
装备购买价格 ≈ f(装备等级, 属性总值, 品质)
```

- 普通装备价格：低（数百~数千金币，视等级）
- 史诗装备价格：中等（数千~数万金币）
- 装备越强属性总值越高，价格越贵

### 5.5 奥秘之神马桶对商店品质的影响

🅰️ **A级**（sfporadnik.pl）

- **奥秘之神马桶（Toilet of the Arcane Gods）**：解锁等级100
- 每升1级光环（Aura Level）：**商店装备品质+1**（可以理解为更高机率出现稀有品质）
- 这是长期提升商店品质的唯一系统途径

## 6. 装备属性与等级缩放

🅲 **C级**（sf-tools 数值反推）+ 🅱️ **B级**（社区观测数据）

### 6.1 护甲值缩放

装备提供的护甲值随角色等级增长，使护甲减伤维持在有效范围：

```
有效减伤% = 护甲值 / 攻击方等级
```

为维持50%减伤（战士上限），所需护甲值 = 攻击方等级 × 50%

| 等级 | 需要的护甲值（维持50%减伤）|
|------|------------------------|
| 10 | 5 |
| 20 | 10 |
| 30 | 15 |
| 50 | 25 |
| 100 | 50 |

> 🗒️ 护甲值的绝对数值本身并不大，重要的是**护甲 / 等级的比值**。

### 6.2 武器伤害值缩放

🅲 **C级**（sf-tools 武器数值逆向）

```
武器伤害 ≈ 等级 × 基础系数 × 职业武器系数 × 随机波动
```

**各等级武器伤害示例**（以战士单手剑为例，C级估算）：

| 等级 | MinDmg（估算）| MaxDmg（估算）|
|------|-------------|-------------|
| 10 | ~4 | ~8 |
| 20 | ~12 | ~20 |
| 30 | ~25 | ~40 |
| 50 | ~70 | ~110 |
| 100 | ~280 | ~420 |

> 🗒️ 武器伤害本身的绝对值并不高，真正使伤害爆炸的是**属性差加成因子**（见战斗系统文档 §5.2）。

## 7. 宝石（Gem）系统

🅱️ **B级**（number13.de 攻略站）

### 7.1 系统简介

- 宝石镶嵌到装备的**宝石槽**中，提供属性加成
- 宝石来自**堡垒宝石矿（Gem Mine）**开采
- 宝石矿等级越高、角色等级越高、堡垒公会等级越高，宝石属性值越大

### 7.2 宝石类型与加成

🅰️ **A级**（官方帮助中心）

| 宝石类型 | 加成属性 |
|---------|---------|
| 蓝宝石（Sapphire）| 力量（Strength）|
| 翡翠（Emerald）| 敏捷（Dexterity）|
| 紫水晶（Amethyst）| 智力（Intelligence）|
| 红宝石（Ruby）| 体力（Constitution）|
| 黄水晶（Topaz）| 幸运（Luck）|

### 7.3 宝石强度决定因素

🅱️ **B级**（number13.de）

```
宝石属性值 = f(角色等级, 宝石大小, 宝石矿等级, 公会骑士大厅等级之和)
```

| 影响因素 | 权重说明 |
|---------|---------|
| 角色等级 | 高等级 = 宝石数值更大 |
| 宝石大小 | 小（Small）< 中（Medium）< 大（Large）|
| 宝石矿等级（堡垒建筑，上限100）| 矿越高 = 宝石越好 |
| 公会骑士大厅总等级 | 公会发展影响宝石质量 |

### 7.4 宝石槽数量

🅰️ **A级**（官方帮助中心）

| 品质 | 宝石槽数量 |
|------|----------|
| 普通装备 | 0槽（默认无槽）|
| 史诗装备 | 0~1槽（随机）|
| 传奇装备 | **1槽（保证）** |
| 铁匠添加 | 可通过铁匠服务额外添加槽位（解锁等级90）|

### 7.5 传奇宝石解锁条件

🅱️ **B级**（社区整理）

- 宝石矿在图书馆中收藏到至少1件传奇装备图册后，才能开采出**传奇宝石**
- 传奇宝石属性值约为普通宝石的 **3~5倍**

## 8. 符文（Rune）系统

🅲 **C级**（sf-tools 符文计算逆向）

### 8.1 符文类型

| 符文类型 | 作用 | 数值上限 |
|---------|------|---------|
| **伤害符文（Damage Rune）** | 提升己方输出伤害 | 60（上限）|
| **抗性符文（Resistance Rune）** | 降低受到的伤害 | 75（上限）|

### 8.2 符文计算公式（见战斗系统 §5.4）

```
符文修正因子 = 1 + (1 - min(75, 目标抗性符文) / 100) × min(60, 己方伤害符文) / 100
```

### 8.3 符文出现在装备上的规则

🅰️ **A级**（官方帮助中心）

| 品质 | 符文槽 |
|------|-------|
| 普通装备 | 无符文 |
| 史诗装备 | 可能有1个符文（随机）|
| 传奇装备 | **1个符文（保证）** |

### 8.4 符文置换（铁匠服务）

- 铁匠（90级解锁）可将一件装备上的符文**转移到另一件装备**
- 费用：铁匠服务费用（金属+奥术碎片）

## 9. 铁匠（Blacksmith）系统

🅰️ **A级**（官方帮助中心）

### 9.1 系统概述

| 参数 | 数值 |
|------|------|
| **解锁等级** | **90级** |
| **货币资源** | 金属（Metal）+ 奥术碎片（Arcane Dust）|
| **资源来源** | 拆解装备获得 |

> ⚠️ **注意**：铁匠在90级解锁，超出本文档30级前范围，但装备本身从1级开始存在，此处记录以备后期使用。

### 9.2 铁匠服务列表

| 服务 | 说明 | 消耗资源 |
|------|------|---------|
| **装备强化（Upgrade）** | 单件装备强化，每次提升属性值 | 金属+奥术碎片 |
| **最大强化次数** | 每件装备最多强化 **20次** | — |
| **宝石槽添加** | 为无槽装备添加宝石镶嵌槽 | 金属+奥术碎片 |
| **宝石提取** | 取下镶嵌的宝石（宝石返还）| 少量消耗 |

| **装备外观修改** | 史诗/传奇装备可修改外观 | 10蘑菇 |
| **物品拆解** | 装备 → 金属+奥术碎片 | — |

### 9.3 每日拆解上限

- 每日最多拆解 **5件**装备
- 拆解是铁匠资源的主要来源

### 9.4 强化收益

🅱️ **B级**（number13.de 攻略）

- 每次强化对属性的提升幅度约为装备基础值的 **1/20**
- 20次满强化后属性提升约 **50%~100%**（视装备类型）
- 高优先级强化：武器（直接影响伤害）> 其他部位

## 11. 收藏册（Scrapbook）系统

🅰️ **A级**（sfporadnik.pl）

### 11.1 系统概述

| 参数 | 数值 |
|------|------|
| **解锁等级** | **10级** |
| **购买方式** | 在魔法商店购买，费用 25 金币 |
| **功能** | 记录玩家见过的所有装备，提供永久属性加成 |

### 11.2 收藏触发条件

- **击败敌人**后：敌人装备自动加入收藏册
- **商店浏览时**：查看的装备自动加入收藏册（无需购买）
- **装备拾取**：任何获得的装备均加入

### 11.3 奖励机制

🅰️ **A级**（sfporadnik.pl）

```
每新增1件装备进入收藏册 → 角色全属性获得永久加成（极小幅度）
```

- 单件装备的加成极小（约 +0.01% 全属性）
- **累积效果显著**：大量刷装备后全属性累积提升可观
- 鼓励玩家积极刷地下城/商店/击败多样化敌人

### 11.4 圣杯（Grail）强化

🅰️ **A级**（sfporadnik.pl）

| 参数 | 数值 |
|------|------|
| **解锁条件** | 85级 + 收藏册达到 1000件以上 |
| **功能** | 在商店/敌人身上**高亮**收藏册尚缺的装备 |
| **战略价值** | 极大提升补全收藏册的效率 |

## 12. 装备策略指导

🅱️ **B级**（玩家社区最优策略）

### 12.1 属性优先级（通用原则）

```
主属性 > 武器伤害 ≈ 体力 > 护甲（对高护甲职业）> 幸运 > 其他
```

- **主属性**（力量/敏捷/智力）直接驱动属性差加成，是最核心指标
- **武器伤害**乘以职业系数后作为基础伤害来源
- **体力**决定血量，确保生存
- **护甲**价值随职业不同而异（法师不需要），高护甲职业（战士/圣骑士）需保持护甲/等级比例

### 12.2 早期（1~30级）装备获取策略

🅱️ **B级**（玩家社区）

| 策略 | 说明 |
|------|------|
| **每小时检查商店** | 等级低时商店刷新成本低，高频刷新性价比高 |
| **优先武器升级** | 武器伤害是最主要的属性差加成倍率基础 |
| **不过度消耗蘑菇刷新** | 前期蘑菇宝贵，等待免费刷新即可 |
| **保留金币买升级** | 属性点升级往往比装备更稳定可靠（1~50级）|

### 12.3 装备评分公式（社区简化版）

🅱️ **B级**（number13.de 攻略）

```
装备分数 = 主属性总值 × 5 + 体力总值 × 1 + 幸运总值 × 1
         + (武器: MinDmg + MaxDmg) × 2
         + 护甲 × 护甲权重（战士0.5，法师0）
```

- 用于快速比较两件装备的综合强度
- 不考虑宝石槽/符文（视为稀有溢价）

### 13.1 装备生成器（核心功能）

```javascript
// 装备生成伪代码
function generateEquipment(playerLevel, slot, quality = 'normal') {
  const baseAttr = playerLevel * BASE_FACTOR[slot];
  const qualityMultiplier = { normal: 1.0, epic: 1.35, legendary: 1.55 };
  
  // 随机主属性
  const primaryAttr = Math.floor(baseAttr * qualityMultiplier[quality] * (0.85 + Math.random() * 0.30));
  
  // 护甲（仅护甲槽位）
  const armor = ARMOR_SLOTS.includes(slot) 
    ? Math.floor(playerLevel * ARMOR_BASE_FACTOR * qualityMultiplier[quality])
    : 0;
  
  // 武器伤害（仅武器槽位）
  let minDmg = 0, maxDmg = 0;
  if (slot === 'weapon') {
    const weaponBase = playerLevel * WEAPON_BASE_FACTOR;
    minDmg = Math.floor(weaponBase * 0.7 * qualityMultiplier[quality]);
    maxDmg = Math.floor(weaponBase * 1.3 * qualityMultiplier[quality]);
  }
  
  // 宝石槽（传奇保证1个，史诗50%概率1个）
  const gemSlots = quality === 'legendary' ? 1 : 
                   (quality === 'epic' && Math.random() < 0.5 ? 1 : 0);
  
  return { slot, quality, primaryAttr, armor, minDmg, maxDmg, gemSlots };
}
```

### 13.2 商店系统核心逻辑

```javascript
class Shop {
  constructor(type, playerLevel) {
    this.type = type;          // 'weapon' | 'magic'
    this.playerLevel = playerLevel;
    this.items = [];
    this.lastRefresh = Date.now();
    this.refreshCooldown = 3600 * 1000; // 1小时
  }
  
  // 刷新商店（自动或手动）
  refresh(mushrooms = false) {
    if (mushrooms || Date.now() - this.lastRefresh > this.refreshCooldown) {
      this.items = this.generateShopItems();
      this.lastRefresh = Date.now();
      return true;
    }
    return false; // 需要等待或消耗蘑菇
  }
  
  generateShopItems(count = 6) {
    const items = [];
    for (let i = 0; i < count; i++) {
      const quality = this.rollQuality();
      const slot = this.randomSlot();
      items.push(generateEquipment(this.playerLevel, slot, quality));
    }
    return items;
  }
  
  rollQuality() {
    const roll = Math.random();
    if (roll < 0.02) return 'legendary';      // 2%
    if (roll < 0.10) return 'epic';            // 8%
    return 'normal';                           // 90%
    // 注：以上概率为估算值（B级）
  }
}
```
