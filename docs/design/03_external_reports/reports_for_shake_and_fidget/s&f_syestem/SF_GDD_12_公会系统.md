## 第一部分：公会基础系统

## 1. 系统概述

### 1.1 系统定位

公会是SF中的**多人协作核心系统**，为玩家提供群体增益（经验/金币加成）、公会副本（突袭）、公会PVP（攻防战）、九头蛇战斗、传送门挑战和社交互动（聊天/邮件）。公会成员通过个人投入金币和蘑菇升级公会建筑，提升全员收益。

🅰️ **A级**（官方帮助中心）

### 1.2 解锁条件

| 项目 | 数值 | 可信度 |
|------|------|--------|
| 创建费用 | **10 金币** + 公会名称 | 🅰️ A级 |
| 创建前提 | 未加入其他公会 | 🅰️ A级 |
| 成员上限 | **50人**（固定，无需升级） | 🅰️ A级 |
| 加入最低等级 | 由会长设定（可为0） | 🅰️ A级 |
| 参与战斗冷却 | 加入公会需满 **24小时** | 🅰️ A级 |

🅰️ **A级**（官方帮助中心 + sfporadnik.pl）

### 1.3 设计目的

- 提供**群体增益**，放大经验和金币收益
- 提供**公会副本**作为额外装备和XP来源
- 提供**PVP玩法**（公会攻防战）
- 提供**九头蛇**作为中期集体目标
- 提供**传送门**挑战作为HP和伤害的永久加成来源
- 促进**社交互动**

## 第二部分：公会等级与权限

## 2. 职位权限体系

### 2.1 三级权限结构

| 职位 | 权限列表 |
|------|---------|
| **会长 (Leader)** | 邀请/踢出玩家、修改公会描述、更换纹章、管理攻防和突袭、提议更换纹章、选择公会宠物 |
| **副会长 (Officer)** | 邀请/踢出玩家（不含会长和其他副会长）、降级不活跃会长、管理攻防和突袭、更换纹章、提议更换纹章 |
| **成员 (Member)** | 提议更换纹章 |

🅰️ **A级**（sfporadnik.pl + 官方帮助中心）

### 2.2 会长不活跃降级机制

| 不活跃时长 | 可降级者 | 触发条件 |
|-----------|---------|---------|
| **21天** | 副会长 | 副会长可降级会长并接任 |
| **365天** | 任何成员 | 成员可降级会长并替换 |
| **14天** | 自动标记 | 成员被标记为"不活跃" |

🅰️ **A级**（官方帮助中心）

## 3. 宝藏与教官升级系统

### 3.1 建筑概览

| 建筑 | 效果 | 最高等级 |

### 3.3 加成计算

| 机制 | 数值 |
|------|------|
| 每级加成 | **0.2%** |
| 个人贡献上限 | **500点/人** |
| 突袭贡献上限 | **500点**（前50次突袭各+10点） |
| 总技能上限 | **1,000点**（500个人 + 500突袭） |
| 公会加成公式 | `总点数 ÷ 5 = 百分比加成%` |

🅰️ **A级**

🅱️ **B级**（number13.de 逆向计算）

### 3.5 关键规则

- 每位成员**个人投入在切换公会时保留**
- 个人投入由**个人金币/蘑菇**支付，非公会资金
- 游戏内也支持用蘑菇升级

🅰️ **A级**

## 第四部分：公会突袭（Guild Raids）

## 4. 副本系统

### 4.1 解锁条件

| 条件 | 数值 |
|------|------|
| 会长等级 | **≥50级** |
| 副本总数 | **150个**（50个名称 × 3个难度） |
| 难度等级 | I（简单）、II（中等）、III（困难） |

🅰️ **A级**（sfporadnik.pl）

### 4.2 副本机制

| 规则 | 说明 |
|------|------|
| 每副本奖励 | 宝藏和教官各 **+2%** |
| 满突袭奖励 | 前50次突袭每次获得**10点技能点**（共500点） |
| 参与规则 | 必须点击"参与"按钮 |
| 错过后果 | 不获得经验，且无法补打 |
| 转移惩罚 | 换公会后可攻击但**不获得经验** |

🅰️ **A级**

### 4.3 纹章系统

由6个元素组成：头盔(Helm)、支撑者(Supporter)、盾牌(Shield)、旗帜(Banner)、头盔秩序(Helmet order)、徽章(Emblem)。所有成员可提议更换，会长和副会长可直接更换。

🅰️ **A级**

## 第五部分：公会攻防战

## 5. PVP系统

### 5.1 进攻

| 规则 | 数值 |
|------|------|
| 发起者 | 会长和副会长 |
| 报名时间 | **10小时** |
| 冷却时间 | **90分钟** |
| 可攻击范围 | 排名差≤20位 或 荣誉差<3,000 |
| 蘑菇投石机 | 3枚导弹，每枚**5蘑菇** |
| 战斗后 | 不报名则不参与 |

🅰️ **A级**

### 5.2 防守

| 规则 | 数值 |
|------|------|
| 报名时间 | **10小时** |
| 未报名惩罚 | 以**50%生命值**自动参战 |
| 防守成功 | 获得名人堂荣誉 |

🅰️ **A级**

### 5.3 蘑菇投石机

- 最多装载 **3枚导弹**
- 每枚花费 **5个蘑菇**
- 向随机敌人发射造成大量伤害
- 战前充能，开战时生效

🅰️ **A级**（sfporadnik.pl）

## 第七部分：九头蛇（Hydra）

## 7. 公会宠物战斗

### 7.1 解锁条件

| 条件 | 数值 | 可信度 |
|------|------|--------|
| 会长等级 | **≥150级** | 🅰️ A级 |
| 会长宠物等级 | **≥100级** | 🅰️ A级 |
| 公会成员数 | **≥10人** | 🅰️ A级 |
| 选择权 | **仅会长** | 🅰️ A级 |

🅰️ **A级**

### 7.2 属性计算

| 项目 | 公式 |
|------|------|
| 属性值 | 取公会中**主属性最高的25名成员**，主属性相加 **÷ 10** |
| 战斗等级上限 | 上述25名成员的**角色等级平均值** |
| 宠物最大等级 | **600级** |

🅰️ **A级**（官方帮助中心）

### 7.3 战斗机制

| 规则 | 数值 |
|------|------|
| 每人每日攻击 | **1次** |
| 伤害计算 | 所有成员伤害**累加** |
| 击败奖励 | XP加成（+25%基础） |
| 连胜效果 | XP加成**递增** |
| 失败惩罚 | 九头蛇失去一头变弱，XP加成**降低** |

🅰️ **A级**

    { level: 1, gold: 5, mushrooms: 0 },

    { level: 3, gold: 25, mushrooms: 0 },
    { level: 4, gold: 100, mushrooms: 0 },

  },

    totalCompleted: 0,

  }

// 恶魔传送门

  },

// 九头蛇
const Hydra = {
  unlockRequirements: {
    leaderLevel: 150,
    leaderPetLevel: 100,
    minMembers: 10
  },
  maxPetLevel: 600,
  calculatePetStats(guild) {
    // 取主属性最高的25名成员
    const top25 = [...guild.members]
      .sort((a, b) => b.mainAttribute - a.mainAttribute)
      .slice(0, 25);
    const totalAttr = top25.reduce((sum, m) => sum + m.mainAttribute, 0);
    return {
      attribute: Math.floor(totalAttr / 10),
      maxLevel: Math.floor(top25.reduce((sum, m) => sum + m.level, 0) / 25)
    };
  }
};
