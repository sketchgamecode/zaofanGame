## 1. 系统概述 (Overview)

**演武场 (Martial Arts Field)** 是《大宋造反模拟器》的核心 PvP 交互系统。它不仅是玩家实战验证、策略比拼的舞台，也是获取声望、铜钱和全服排名的主要途径。

### 1.1 设计目标
*   **强交互感**：通过与真实玩家（镜像）的对战，建立“江湖社交”基础。
*   **长期激励**：引入荣誉排名系统，高排名玩家将获得实质性的战斗增益。
*   **低门槛高反馈**：1 级入口可见，自动战斗，快速结算。正式奖励和冷却按 server 配置控制。

## 2. 核心逻辑 (Core Logic)

### 2.1 对手匹配机制 (Matching)
*   **触发点**：玩家进入演武场页面或点击“换一批”按钮。
*   **筛选池**：全服**英雄谱 (Hall of Fame)** 中的所有活跃角色。
*   **匹配规则**：
    1.  系统从英雄谱中随机抽取 **3 名对手**。
    2.  对手的荣誉排名通常处于玩家当前排名的 **80% - 130%** 范围内（确保挑战难度适中且有上升空间）。
    3.  前端展示：展示对手的昵称、头像、等级、职业、荣誉值。

### 2.2 战斗规则 (Combat Rules)
*   **镜像对决**：攻击方实时挑战防御方的存档镜像（快照）。
*   **先攻判定**：**荣誉值（Honor）较高者先攻**。荣誉相同时随机。
*   **战斗回放**：沿用 `Combat_System_Spec_V1.md` 的统一战斗引擎，生成 `BattleResultV2` 供前端播放。

### 2.3 荣誉系统 (Honor & Ranking)
*   **公式原则**：采用 `Combat_System_Spec_V1.md` §6.4 的 Elo 变体算法。
    *   **胜利**：获得荣誉值。击败排名更高的对手获得更多，反之极少。
    *   **失败**：扣除荣誉值。输给排名较低的对手扣除更多。
*   **数值激励**：
    *   首版不把荣誉直接混入基础伤害，避免 PvP 排名优势滚雪球。
    *   P1 可追加“荣誉/竞技场等级差影响暴击倍率”的 S&F 进阶规则，但必须由战斗引擎统一处理。

## 3. 世界填充系统 (World Population / Bot System)

由于新服启动阶段真实玩家较少，为确保演武场体验，引入自动填充机制。

### 3.1 Bot 生成规则
*   **初始规模**：服务器初始化时，自动生成 500 个不同等级段的 Bot。
*   **数值对标**：
    *   **职业分布**：猛将 40%, 游侠 30%, 谋士 30%。
    *   **属性配比**：Bot 的属性点分配遵循 S&F 经典权重（主属性:体质:幸运 = 1:0.8:0.4）。
    *   **装备分级**：Bot 会根据等级“虚空生成”一套符合该等级战力的装备，装备词条符合职业倾向。
*   **动态管理**：
    *   当真实玩家数超过 2000 时，系统将逐步剔除排名较低的 Bot。
    *   Bot 之间会进行每日 2-3 次的虚拟对战，产生荣誉值浮动，营造“活服”错觉。

## 4. API 接口定义 (Actions)

### 4.1 `ARENA_GET_INFO`
获取演武场状态。
*   **返回**: 剩余免费次数、下次挑战冷却时间、当前 3 个候选对手快照。

### 4.2 `ARENA_REFRESH_CANDIDATES`
刷新 3 个候选对手。
*   **Payload**: `{}`
*   **返回**: `candidateSetId` + `ArenaOpponentPreview[3]`。

### 4.3 `ARENA_FIGHT`
发起挑战。
*   **Payload**: `{ targetPlayerId: string, candidateSetId?: string }`
*   **校验**: 冷却中或无次数则失败。
*   **结算**: 返回 `BattleResultV2` + `replayId` + 荣誉变动 + 资源变动 + 排名变化。
*   **回放保存**: 竞技场战斗必须自动保存到邮箱“战斗回放”页签，详见 `Combat_System_Spec_V1.md` §6。

### 4.4 `ARENA_SKIP_COOLDOWN`
跳过 10 分钟冷却。
*   **消耗**: 优先 1 沙漏；无沙漏时消耗 1 令牌。

## 5. 英雄谱 (Hall of Fame Hub) 规格

英雄谱不仅是玩家排名的列表，它是整个服务器的**社交与竞争枢纽**。

### 5.1 多维排行榜 (Tabs)
英雄谱包含以下五个核心标签页，按不同维度进行全服排名：
1.  **英雄谱 (Heroes)**：基础标签页，按“演武场荣誉 (Honor)”排名。
2.  **公会榜 (Guilds)**：按公会总荣誉排名。
3.  **要塞榜 (Fortresses)**：按要塞等级与防御强度排名（25 级解锁后启用）。
4.  **收藏册榜 (Scrapbook/Glory)**：按图鉴收集完成度排名。
5.  **灵宠榜 (Pets)**：按宠物战力排名。

### 5.2 列表项交互 (List Interactions)
在任何排行榜中，点击玩家行应支持以下交互：
*   **查看详情**：弹出该玩家的角色面板镜像（Character Panel Preview），查看其属性、装备。
*   **直接挑战 (Fight)**：行末有一个“双剑”图标，点击可直接消耗次数并在演武场挑战该玩家。
*   **私信 (Mail)**：行末有一个“信封”图标，跳转至私信界面。

### 5.3 搜索与定位 (Navigation)
*   **精准跳转**：支持输入排名数字直接定位到该名次的区间。
*   **搜索角色**：输入昵称搜索，系统自动跳转到该玩家所在的排名页。
*   **定位自己 (Me)**：点击“居中”按钮，快速定位到玩家自身的排名位置。
