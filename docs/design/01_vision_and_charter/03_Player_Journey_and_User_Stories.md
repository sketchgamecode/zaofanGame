# Player Journey and User Stories V1

本文档从玩家视角描述“大明体制内升迁”包装下，玩家如何理解、进入并持续游玩当前系统。

它不替代服务端机制文档。机制细节仍以 `docs/design/04_system_specs/Power_Structure_and_World_Actor_System_V1.md` 为准。本文件只回答一个问题：玩家看到这些系统时，应该觉得自己正在扮演什么、选择什么、承担什么后果。

---

## 1. 核心体验一句话

玩家扮演一个大明权力机器里的小人物，从出身和职司入局，在京城各权力场所之间办差、置装、站队、得罪人、攒权柄，并尽量避免被牵连清洗。

---

## 2. 体验边界

V1 的主舞台是 **京城权力地图**。

玩家不是在大明版图上旅游，也不是在多个城市之间经营商路。玩家每天面对的是京城里的权力入口：紫禁城、北镇抚司、神机营、都察院、国公府、盐商会馆、流民营等。

大明版图可以在 V2 作为外派案件、边镇军务、盐路差事、流民迁徙的目标背景出现，但不应抢走 V1 的核心焦点。

V1 的体验重点：

1. 看见京城中各权力集团的存在。
2. 明白自己属于哪个集团。
3. 明白每次任务是谁发布、打击谁、得罪谁。
4. 明白收益和牵连不是孤立数值，而是站队后的后果。
5. 明白权柄总量有限，自己的上升意味着别人被挤下去。

---

## 3. 新玩家前十分钟

### 3.1 创建角色

玩家先选 **出身**，再选 **职司**。

出身要让玩家立刻理解自己在大明社会里的位置：

1. 军户不是普通战士，而是被卫所制度绑住的军事人口。
2. 市井商贾有钱，但名分低，容易被税、盐、贡品体系盯上。
3. 清流世家有名分和门生，但并不天然安全。
4. 流民秘社在体制外求活，能走暗路，也更容易被清剿。

职司要让玩家理解自己服务的权力机器：

1. 神机营走军械火器路线。
2. 厂卫走缉拿、诏狱、密查路线。
3. 边镇走军功、守城、家丁路线。
4. 清流或术士走名分、弹劾、天命和文书路线。

### 3.2 第一次看见自己

玩家进入游戏后，应在角色卡上看到：

1. 头像、姓名、等级。
2. 所属权力集团。
3. 战力评分。
4. 当前最高牵连。

玩家不需要立刻理解所有机制，但要知道自己不是一个无根冒险者，而是已经被某个权力系统登记在册的人。

### 3.3 第一次进入京城

玩家进入京城地图后，应看到：

1. 各地点属于不同权力集团。
2. 每个地点有不同服务入口。
3. 每个地点有角色数量和权柄占比。
4. 自己可以去哪，哪些地方暂时只是展示，哪些地方会提供任务或商店。

### 3.4 第一次办差

玩家接第一个任务时，应看到：

1. 发布方是谁。
2. 目标方是谁。
3. 案件类型是什么。
4. 可能增加哪一方的牵连。
5. 奖励是否值得这个风险。

完成任务后，玩家应看到牵连变化，而不是只看到经验和铜钱。

---

## 4. 日常循环

V1 的基础日常循环：

1. 进入京城地图，查看各集团权柄分布。
2. 选择一个地点进入。
3. 查看该地点提供的差事、商店、副本或竞技服务。
4. 比较收益、战力需求、目标集团和牵连代价。
5. 执行任务或战斗。
6. 结算奖励、牵连和可能的权柄变化。
7. 回到角色面板检查战力、装备和风险。
8. 决定继续讨好当前集团，还是冒险接其他集团的活。

---

## 5. 玩家每次决策应回答的问题

每个新系统、新入口、新任务，都应尽量让玩家回答下列问题中的至少一个：

1. 我这次是在替谁办事？
2. 我这次是在打击谁？
3. 这个奖励是否值得我增加牵连？
4. 我所属的集团现在强不强？
5. 我是不是已经太显眼，快成为别人的目标？
6. 我应该稳妥做同阵营差事，还是跨阵营捞一笔？
7. 我是要继续表忠心，还是给自己留后路？

如果一个功能只提供奖励，不制造任何站位、风险或后果，它就没有充分服务当前题材。

## 6. 阶段目标

### 6.1 早期目标

玩家早期目标是活下来并找到路线：

1. 确认自己的出身和职司适合哪类任务。
2. 搞清楚哪些地点对自己友好。
3. 通过基础差事获得装备和铜钱。
4. 避免过早积累过高牵连。

### 6.2 中期目标

玩家中期目标是稳定站位并开始积累权柄：

1. 在某个集团内获得较高 standing。
2. 解锁更高风险和更高收益的差事。
3. 参与历史案件副本。
4. 开始与世界角色池里的具体角色发生冲突。
5. 从普通打手变成某个集团可用的人。

### 6.3 长期目标

玩家长期目标是争夺权柄并承担被清洗的风险：

1. 在集团内成为核心人物。
2. 拥有可见的权柄份额。
3. 影响集团之间的强弱变化。
4. 在历史案件和离线对抗中成为别人会遇到的目标。
5. 在收益、忠诚、背叛和自保之间长期取舍。

## 7. User Stories

### 7.1 出身与职司

作为一个新玩家，我想先选择出身，再选择职司，这样我能理解大明社会身份先于个人能力。

作为军户玩家，我想看到军户被卫所制度束缚的文案和优势劣势，这样我不会把它误解成普通战士种族。

作为市井商贾玩家，我想看到钱、税、盐引和名分低之间的关系，这样我能理解为什么赚钱路线也会带来风险。

作为清流世家玩家，我想看到名分、门生、弹劾和门阀利益，这样我能理解自己不是单纯的读书人模板。

作为流民秘社玩家，我想看到暗线、逃户和清剿风险，这样我能理解自己为什么能接脏活，也为什么容易被体制敌视。

### 7.2 京城地图

作为玩家，我想在京城地图上看到不同权力场所，这样我能把任务、商店、副本和竞技理解为拜访不同门路。

作为玩家，我想看到地点归属的集团和权柄占比，这样我能知道这不是普通菜单，而是权力版图。

作为玩家，我想看到一些暂未开放但有包装的地点，这样我能预期后续系统会挂在同一张地图里。

### 7.3 任务与牵连

作为玩家，我想在接任务前看到发布方和目标方，这样我知道这不是普通刷怪，而是在替某个集团办事。

作为玩家，我想在任务前看到牵连预估，这样我能判断这次收益是否值得冒险。

作为玩家，我想在任务结算时看到牵连变化，这样我能感受到选择留下了持久后果。

作为玩家，我想同阵营任务更顺手、跨阵营任务更高风险，这样站队才有真实意义。

### 7.4 副本与历史案件

作为玩家，我想蓝玉案这类副本显示发起方、目标方和历史钩子，这样我知道自己是在参与权力清洗。

作为玩家，我想副本敌人来自世界角色池，这样我遇到的不是抽象怪物，而是某个集团里的具体人物。

作为玩家，我想胜利后看到牵连或权柄后果，这样历史案件不只是一次战斗。

### 7.5 世界角色池

作为玩家，我想知道世界里有一批真实或半真实的角色都在争权，这样我会觉得自己处在同一个权力生态里。

作为玩家，我想随着真实玩家变多，假角色逐步减少，这样世界会从冷启动过渡到玩家驱动。

作为高权柄玩家，我想自己可能成为其他案件或任务的目标，这样高收益也带来被围剿的压力。

### 7.6 权柄

作为玩家，我想看到世界权柄总量有限，这样我能理解上升不是无限刷数值，而是夺走别人的位置。

作为玩家，我想看到集团权柄变化，这样我能判断自己站队的集团是在变强还是变弱。

作为玩家，我想权柄不能通过普通商店直接购买，这样它不会退化成另一种货币。

## 8. 体验验收标准

新增或修改系统时，应至少满足以下标准：

1. 玩家能说出这个系统属于哪个大明权力场景。
2. 玩家能看出自己在替谁获利。
3. 玩家能看出自己可能得罪谁。
4. 玩家能看出短期奖励和长期风险。
5. 玩家能在角色面板或地图上看到某种持续后果。

不满足这些标准的功能，应先补包装或补反馈，再进入正式实现。

## 9. 术语约束

优先使用：

1. 出身
2. 职司
3. 差事
4. 京权地图 / 京城权力地图
5. 权柄
6. 牵连
7. 站位
8. 投名状
9. 案件
10. 门路

避免回退到：

1. 种族
2. 职业
3. 普通任务
4. 怪物据点
5. 世界地图旅游
6. 无限产出的声望货币
