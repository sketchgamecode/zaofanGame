# ZaoFanGame 题材设定与文案写作规范

本文档为内容设计、文案 Agent 及 UI/UX 设计提供指导，确保游戏题材、系统命名、角色包装和 UI 文案保持统一。

---

## 1. 核心题材：大明体制内升迁

本作不再采用泛古风、跨朝代、古典文学大杂烩包装。新的题材主轴是：

> 玩家不是泛古风冒险者，而是一个在大明权力机器中求上升、争差遣、置装备、攒威名的小人物。

游戏世界围绕“大明体制内升迁”展开。玩家从低微出身入局，在军营、厂卫、内府、边镇、清流、民间秘社等暴力与官僚系统之间办差、捞钱、置装、升阶。所有系统包装都应服务于这条主线，而不是随意切换到仙侠、江湖、神魔或跨朝代题材。

### 题材关键词

1. **大明官僚机器**：品级、差遣、考绩、衙门、案牍、火漆、腰牌、文书、奏折。
2. **暴力机关升迁**：神机营、锦衣卫、西厂、卫所、边镇、诏狱、抄家、缉盗、追赃。
3. **黑色幽默**：欠饷、冒功、买官、背锅、假货、宫中流出、官样文章。
4. **高数值跨越感**：从小旗、校尉、番役、书吏一路爬到能调兵、查案、抄家、入阁边缘的荒诞高度。

## 2. 玩家身份：从小人物到权力系统成员

玩家角色的核心幻想不是“拯救天下”，而是“在一个荒诞、残酷、讲规矩又暗藏门路的体制里往上爬”。

### 系统包装原则

| 游戏系统 | 包装方向 |
| :--- | :--- |
| 角色等级 | 资历、身份、差遣层级、江湖排名或官场名声 |
| 任务 | 办差、缉盗、护送、追赃、抄家、清剿、传令 |
| 商店 | 神机营、内务府、私渠、军需库、赃物铺 |
| 装备 | 军械、官服、腰牌、符印、密札、宫中流出物 |
| 竞技场 | 校场比武、厂卫私斗、诏狱斗狠、衙门考绩 |
| 副本 | 案件、差事、边镇清剿、逆党搜捕、府库追赃 |
| 声望 | 官声、厂卫威名、圣眷、江湖风评 |
| 付费/特殊资源 | 令牌、火漆、密旨、贡品、门路 |

所有新系统命名都优先从上述语义池里选择。

## 3. 出身系统：替代传统“种族”

前端和文案中应避免使用“种族”作为玩家可选项。对应概念统一包装为 **出身**。出身决定初始天赋、收益倾向或小幅被动差异。

### 3.1 军户 / 边塞老兵

**背景**：祖辈隶属卫所，辽东吃沙，东南抗倭，穷得响叮当，但皮实耐操。

**天赋方向**：生命、护甲、生存能力更高；金币收益略低或资源获取较苦。

**示例被动**：`军饷难发`：基础气血额外提升，办差铜钱收益略降。

**视觉方向**：胡茬、黝黑、破旧鸳鸯战袄、旧军牌。

### 3.2 市井 / 江南商贾

**背景**：苏州、南京、杭州一带商贾出身。士农工商里排得不高，钱袋却不薄。

**天赋方向**：铜钱收益、交易折扣、商店刷新收益。

**示例被动**：`腰缠万贯`：办差和副本铜钱获取提升。

**视觉方向**：丝绸大褂、玉扳指、圆润体态、和气生财但略显欠揍的笑。

### 3.3 清流 / 世家子弟

**背景**：诗书传家的江南大族，祖上出过进士。肩不能挑，手不能提，但很会讲规矩。

**天赋方向**：经验收益、声望收益、文书类事件加成。

**示例被动**：`科举保送`：办差经验值提升。

**视觉方向**：面容俊朗、折扇、青衫、眼神清高。

### 3.4 流民 / 秘社信众

**背景**：灾荒、欠饷、逃户、秘社香会搅在一起。与旧秩序格格不入，行事诡异。

**天赋方向**：暴击、锁血、逆境反击、异常抗性。

**示例被动**：`残香护命`：低气血时有概率触发短暂保命效果。

**视觉方向**：破衣、头巾、香囊、狂热眼神。

> 注意：民间宗教和秘社包装应做架空处理，避免写成现实组织宣传。

## 4. 职司系统：替代传统“职业”

前端可以使用“职司”或“派系”替代“职业”。职司决定战斗机制、装备倾向、主属性和技能风格。

### 4.1 神机营

**定位**：高爆发远程火器，伤害高、波动大、身板脆。

**主属性包装**：机巧 / 谋略。

**装备方向**：五雷神机、佛郎机手铳、鸟铳、火药囊、防震轻甲。

**技能梗方向**：

1. `火药过载`：概率造成高额伤害，也可能炸膛自损。
2. `大将军炮`：重火力轰击。
3. `营造算学`：提升火器命中和伤害上限。

### 4.2 锦衣缇骑 / 西厂番子

**定位**：敏捷刺杀，高闪避、高暴击、流血和恐惧。

**主属性包装**：身法。

**装备方向**：绣春刀、飞镖、暗弩、飞鱼服、腰牌。

**技能梗方向**：

1. `先斩后奏`：无视部分护甲。
2. `诏狱伺候`：施加流血或恐惧。
3. `缇骑夜行`：提升闪避和先手。

### 4.3 卫所猛将 / 边防总兵

**定位**：力量重甲，气血高、护甲高、擅长格挡。

**主属性包装**：膂力。

**装备方向**：雁翎刀、戚氏军刀、长刀、锁子甲、凤翅盔。

**技能梗方向**：

1. `天子守国门`：短时间大幅提升防御。
2. `家丁死士`：召唤亲兵抵挡伤害。
3. `边镇老卒`：低血量时提升抗性。

### 4.4 钦天监术士 / 清流言官

第四职司应在两条方向中选择其一，避免混成“理学大儒 + 算命天师”的双重设定。

**钦天监术士方向**：更适合视觉表现，使用天象、青词、符箓、嘉靖梗。

**清流言官方向**：更适合黑色幽默，使用弹劾、诛心、官场嘴炮、道德压制。

**主属性包装**：谋略 / 气运。

**技能梗方向**：

1. `青词献媚`：提升气运和会心。
2. `圣人诛心`：令敌方混乱或降低攻击。
3. `弹劾成册`：叠加负面状态。

## 5. 基础属性命名

底层数值可以继续保留通用字段，但玩家可见包装应使用大明语境。

| 底层属性 | 玩家可见名称 | 说明 |
| :--- | :--- | :--- |
| strength | 膂力 | 体魄、武勇、近战压制 |
| agility | 身法 | 闪避、潜行、先手 |
| intelligence | 谋略 / 机巧 | 火器、算学、权谋、术法 |
| constitution | 根骨 | 气血、生存、抗性 |
| luck | 气运 | 会心、奇遇、保命、爆发 |

若某职司需要更精确包装，可在职业说明中局部使用“机巧”“天机”“官场手腕”等词，但基础属性面板应保持统一。

## 6. 文案风格边界规则

### 允许的写法

1. **官样文章式黑色幽默**：一本正经地描述荒唐制度，例如欠饷、冒功、走门路。
2. **古代语境化的现代人性梗**：可以写克扣、甩锅、关系户、假货，但必须包装进大明场景。
3. **历史梗轻度变体**：可使用厂卫、内务府、神机营、青词、边镇、卫所、诏狱等语义。
4. **小人物升迁叙事**：文案应让玩家感觉自己在办差、谋升、攒资历。
5. **荒诞但不出戏**：可以夸张，但不要变成现代段子或仙侠爽文。

### 禁止的写法

1. **泛古风大杂烩**：不要随意跳到西游、封神、三国、水浒、金庸、聊斋等跨题材包装。
2. **传统奇幻种族职业**：禁止在玩家可见文案里使用精灵、兽人、法师、战士等直白西幻词。
3. **现代流行语**：禁止使用“YYDS”“绝绝子”“emo”“躺平”等。
4. **现代科技概念**：禁止出现手机、直播、算法、外卖等。
5. **打破第四面墙**：不能出现“这是个游戏”“玩家点击”等元叙事。
6. **严肃历史模拟口吻**：本作不是历史教材。文案应有戏谑和角色扮演感。

## 7. 标准文案格式

### 装备描述

格式：`【简短定语】+ 正文 + 讽刺或转折`

示例：

> 【营中旧造】刀身刻着神机营火漆，账册上写得清清楚楚。至于是新领的，还是谁库里少了一把，便不是买主该问的事。

### NPC 入场对白

格式：`身份称谓 + 场所利益 + 一句黑色幽默`

示例：

> 神机营军械入册出库，刀枪弓弩、甲胄护具皆可照价购买。莫问来路，只看银钱。

### Boss / 敌人描述

格式：`第三人称旁白 + 官场/暴力机关背景 + 荒诞结局`

示例：

> 此人原是边镇管粮小吏，三年间把军粮、马料、棺材本都算进了亏空。事发后倒先学会了刀法，专砍来查账的人。

旧版“中国古代历史文学大杂烩宇宙”仅作为历史草案保留，不再作为新增系统、角色、装备、副本和 UI 文案的指导方向。
